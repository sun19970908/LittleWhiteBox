# 格式修复 — 使用说明

## 文件

|格式修复核心| 引擎。每条 AI 回复后自动跑规则。 |
|格式修复生成规则 | 让 LLM 帮你写新规则，点按钮触发。 |

## 第一次用

小白x循环任务导入两个json、全部启用。

## 改规则（手写）
正则和代码可以共存，按顺序执行

```js
// 正则
{ name: '示例', pattern: '源文', replacement: '替换', flags: 'g' }

// 代码
{ name: '示例', code: (text) => text.replace(/x/, 'y') }
```

## 让 LLM 帮你写新规则

### 用生成规则的循环任务

1. 编辑格式修复生成 的 顶部两个常量：
   - `GEN_PRESET_NAME` = 新 preset 名字（例：`鬼灭之刃`）
   - `GEN_REQUEST` = 描述要修的格式问题
2. 任务面板点 **"格式修复生成规则"** 按钮
3. 成功后自动复制完整 task JSON 到剪贴板，弹 toastr
4. 新建 `循环任务`，粘剪贴板内容，楼层间隔1，楼层类型llm，时机ai回复后，注册按钮

### 也可以直接把提示词发送给网页deepseek，然后粘贴到模板里，改一下里边的模板名

手动发送给ai的提示词：
```
[system]
你是修复规则作者。用户会描述格式问题并附上最近一条 AI 回复。请产出能在运行时由脚本确定性执行的修复规则，输出一个 JSON 数组，每条规则二选一：
1. 正则替换规则（优先）：
   {"name":"简短名","pattern":"正则源码（不带定界符）","replacement":"替换文本，可用 $1 等引用捕获组","flags":"g"}
2. 代码规则（仅当正则表达不了提取、重排、条件逻辑等）：
   {"name":"简短名","code":"函数体字符串；参数 text 是正文，必须 return 修复后的正文"}

硬性要求：
- pattern 必须是合法 JS 正则源码；replacement 必须是字符串
- 规则只修格式形态，不得改动正文语义内容
- 只输出 JSON 数组本身，不要解释、不要代码围栏

[user]
[格式问题描述]
（你的要求）
[最近一条 AI 回复]
（示例消息）
```

## 多套配置

每份"配置 - xxx" task 是一套 preset
切换 = 点哪个配置 task 的按钮，弹 toastr "已切换到：xxx"，下一条 AI 回复用新 preset。


## 注意：
生成规则时必须关闭酒馆助手脚本里的角色脚本的MVU，否则UpdateVariable代码块会被吞掉
