# 活页面检查验收契约

- 用户没给 class 时，可以按可见文字找到当前页面元素、读取状态；检查不执行页面按钮或改变表单。代价：误操作卡数据。
- 初始化就抛错或资源失败时，小白X渲染的页面保留可读诊断；捕获不吞原异常、不把拒绝的 Promise 改成已处理。代价：静默改变卡脚本行为。
- 结果超过一页时，续读能取完整内容；旧文档、已移除页面不能被旧标识误指向新页面。代价：错误证据、串聊天。
- 诊断全局有容量上限，溢出可见；页面销毁、切聊天和模块清理释放记录及监听，不写聊天存档。代价：内存泄漏、聊天存档膨胀。
- 助手关闭 JS 执行权限时仍能使用只读检查；取消或失败不冒充改写成功。代价：工具协议错误。
- 写回后仅重建指定楼层的显示，不改正文、不保存聊天、不广播消息事件；托管宿主保持唯一渲染所有者。代价：重复结算、误执行任务、双份页面。
- 重建调用按有副作用处理，原有变量 API 和宿主 API 仍可用；新旧页面标识不能混用。代价：漏确认、协议错误、错误验收。

源码测试覆盖内存与协议；隔离真实浏览器覆盖初始化、DOM/布局、资源失败、分页和页面生命周期。不要断言样例文案或固定 CSS 数值。

实际助手闭环使用隔离卡验四类现象：文字挤窄、按钮没反应、白屏、保存后未生效。用户输入不提供元素名或截图；根据工具轨迹核对定位、写回和新页面复查。付费模型结果和浏览器证据只保存在本地 output，不作为固定文案或布局断言。
