# Maintaining reusable skills

## When is a workflow worth keeping?

A skill records a stable procedure that will help with similar work later. Suggest one when the workflow is understood and the user wants to reuse it. Read the catalog to see whether an existing skill already covers it.

## How should an existing skill change?

Read the skill before updating it. Keep the useful instructions and change the parts the user requested. Update or delete existing skills when the user explicitly requests that change. The management tools maintain the skill body and catalog together.
