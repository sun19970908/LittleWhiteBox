# 向量缓存包的边界

聊天正文、`stateAtoms`、`l0Index` 和总结属于酒馆聊天 metadata/聊天记录。向量包不是记忆备份，所有导入结果（成功、失败、取消）都不能修改这些数据。

## 当前格式：ZIP v3

包只包含 `manifest.json` 及 `chunks.bin`、`states.bin`、`relations.bin`、`events.bin`。manifest 保存聊天标识、模型指纹、维度、记录标识/楼层和输入摘要，不保存 L0、L1 或事件原文。数值采用 little-endian float32，关系向量仅为实际存在的记录打包，不补零。

来源摘要是 `SHA-256(JSON.stringify([kind, embeddingInput]))`，在实际向量请求的输入确定后记录。它用于检测来源错配，不是签名或可信来源认证。不能在导出时根据最新文本给旧向量补摘要。

现有向量表中的 `sourceHash`、L0 的 `relationHash` 与向量一起持久化：它们描述生成该向量的输入，需要跨重启保留；所有者是对应向量记录，替换或清理向量时一并删除。不新增表、schema 索引、持久化导入快照、锁或缓存。

旧浏览器缓存没有摘要时仍可供现有检索使用，但不能导出为有来源证明的新包。导出明确要求完整重建向量；不会重新提取 L0，也不会静默产生 API 请求。向量重新生成后该限制自然解除。

导入导出不读取或比对当前 Embedding 模型配置；未配置或配置了不同模型都不阻止缓存搬运，也不自动修改配置、调用模型。导出从向量记录保留其生成模型指纹，导入原样保存包内指纹。当前格式一包声明一个来源模型，不能把混合来源的记录伪标为同一个模型；维度、数值及包内来源信息仍需自洽。检索和补算时才检查当前模型能否使用该缓存，同维度不代表同向量空间。

L1 的 `meta` 是增量构建进度，不是各层向量的模型事实来源：L1 失败而 L0 成功时，可以没有 `meta`，但仍能导出合法的 L0 缓存。

## 恢复流程

`storage/package` 拥有格式、来源校验和存储事务；`vector-io.js` 仅负责本地文件或酒馆服务器 ZIP 的取放，两个入口共用同一套实现。

1. 捕获当前聊天的只读内容和文本过滤规则；不使用会初始化或迁移 metadata 的 getter。
2. 校验包结构、唯一标识、数值和当前聊天 ID；模型指纹来自包内，不与当前配置比较。
3. 用现有 `chunkMessage` 从当前正文重建 L1，并核对每条向量的实际输入摘要。L0 关系输入和事件输入与生成入口共享定义。
4. 以一笔 IndexedDB 事务替换当前聊天的检索缓存。每个异步写入后检查取消、切聊天及来源变化；失败则整笔回滚。不触碰其他聊天。
5. 提交后失效检索运行时和词法索引。L1 完成楼层从实际恢复覆盖范围派生，不相信包内宣称的完成位置。

完成边界之前连续，不代表之后没有可用缓存。后续 L1 增量补算将片段、向量与完成边界一起提交；Embedding 失败不写库，写入失败或取消则由事务恢复原记录，不按楼层范围删除已恢复的缓存。

这不是换卡导入入口。跨聊天 ID、修改过的正文/锚点/事件或不同过滤结果都会被拒绝；先打开原聊天并使用匹配的文本过滤规则。源设备已有旧片段且当前过滤结果不同，也不能将其导出为新来源的向量。

## 旧文件兼容

只在解析入口支持正式线真实导出的 ZIP v2；转换后只保留当前缓存模型。`tests/fixtures/vector-package-v2.json` 是运行其记录的 upstream 提交中的真实 `exportVectors` 所得 ZIP，输入是虚构数据。

- v2 的 L1 文本及 L0 原文只用于核对输入，绝不回写聊天。
- v2 事件仅带 ID，无法证明来源：不恢复这部分，并返回 `legacy_events_omitted`，界面提示使用“补齐缺漏”。如果整个包都无可验证向量，则拒绝整次恢复，保留当前缓存。
- 原解析器虽然放行过版本号 1，但没有可核实的 v1 导出格式/真实样本；不再猜测其布局。未知版本明确拒绝。
- 只有明确停止支持已有 v2 备份后才能删除 `legacy-v2.js` 和对应 fixture；历史语义不进入日常生成或检索。

服务器备份仍使用原文件名规则和酒馆文件 API，不自动同步，也不改变聊天文件。删除本功能只需删除包模块、传输入口及注册，并清理其服务器备份文件；保留聊天记忆和正常检索缓存。

## 验证

`node --test modules/story-summary/tests/vector-package.test.js` 覆盖真实 ZIP、内存 IndexedDB 事务、跨入口一致性、模型配置独立性、来源错配、未知来源、取消/失败/切聊天、旧包转换以及 metadata 不变性。不调用真实模型或读写真实聊天。
