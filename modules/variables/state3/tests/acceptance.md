# 必要验收契约

| 编号 | 必须发生 / 绝不能发生 | 出错代价 |
| --- | --- | --- |
| K1 | 所有入口提交同一批修改时，使用同一套转换、动作、关联计算和校验 | 状态错误 |
| K2 | 整体替换、子字段修改和动态字段都不能绕过权限或直接改派生值 | 存档被污染 |
| K3 | 模型接口允许可选对象、动态成员、数组的合法写入，保留最终规则检查 | 协议不可用 |
| K4 | 任何操作、触发、校验失败或计算取消，整批不发布；触发不收敛能定位规则链 | 半笔扣款或奖励 |
| K5 | 重开使用已存状态；尾删、切 swipe 只恢复效果；整理正文不解释历史；单元素记录不随数组增长 | 存档丢失、膨胀、重复奖励 |
| K6 | 试算不改变聊天，卡保存只替换自己的键，保存失败不重算 | 覆盖他人数据、重复扣款 |
| K7 | 异步提交不能跨聊天、跨 swipe 或覆盖变过的变量起点 | 串档 |
| K8 | 自定义函数不能访问宿主、网络、存储或不可恢复的外部状态；取消后 Worker 退出 | 数据泄露、浏览器卡死 |
| K9 | V5 资料交接、一次提交、一次纠错使用 Agent API 协议；保留原提交和诊断 | 请求失效或重复更新 |
| K10 | 保存未返回时，切 swipe、尾删仍立即恢复；保存串行并合并待存状态，失败只重试保存，不串聊天、不以旧结果覆盖新选择 | 回滚丢失、串档、旧状态覆盖存档 |
| K11 | 当前值只存原生聊天变量；原宏、面板、结算、重载读同一份；其他变量不被覆盖；原生修改使旧异步提交失效 | 串档、覆盖用户修改 |
| K12 | RP 描述宏只含字段含义；更新器读取更新依据；重新更新时读起点而非旧结果；预览不改存档 | 模型输入污染、错误更新 |
| K13 | 数组混合增删不复制无变化元素；对象递归展示变化；AI 说明按原操作对应、只活在本次结果，切换或回滚后不复活 | 存档膨胀、错误归因 |
| K14 | 新 swipe 快速终止后恢复原分支变量和按钮，不重复执行；正常新 swipe 仍自动更新一次 | 状态错乱、重复奖励 |

| K15 | 卡上保存的规则是唯一规则源；规则变更不重置变量、不取得外部变量所有权；在途操作不能混用新旧规则；导入完整覆盖规则及函数、不覆盖草稿与其他卡内容 | 覆盖用户数据、混用规则 |
| K16 | 旧楼切换保留后续已确认变化及必要父结构；反复切换、撤销后楼、尾删、保存重开一致，不保留无关旧字段或重复执行动作 | 回滚丢失、重复奖励 |
| K17 | 原生变量写回、宏、面板、结算及重开保留字符串与数字、布尔、null、数组、对象的类型 | 隐性类型损坏 |
| K18 | 库差量保存重载后仍可正反向恢复；嵌套数组混合增删、重复元素及特殊字段名不变形、不丢字段，修改一项不复制其他项 | 存档损坏、隐性丢数据 |

函数测试仅覆盖以上契约。实际构建包还须在隔离酒馆完成：空卡制作、试算保存、世界书宏、手动/自动/正文/API 提交、保存重开、尾删、swipe、整理聊天、失败恢复、长聊天增量与耗时。
