# 独立更新专用世界书条目

| 契约 | 必须发生 / 绝不能发生 | 出错代价 |
| --- | --- | --- |
| U1 | 2.0 独立更新及请求预览只临时启用标题以前缀常量标记的关闭条目，其他条目及宿主的触发、位置、排序、宏处理保持原义 | 更新规则缺失或错误结算 |
| U2 | 普通聊天、其他后台组装及未选择这项投影的 3.0 请求不启用这些关闭条目，原始条目和磁盘文件不被改写 | 更新指令污染正文、卡配置被改写 |
| U3 | 组装成功、失败、取消、切聊天或被其他生成打断后，专用条目监听立即移除；排队的请求尚未开始时不安装监听 | 跨请求泄漏、串聊天 |

函数测试覆盖以上契约。实际宿主验收使用隔离世界书和聊天，检查构建包的请求预览、宏展开、D0 插入及普通请求隔离；不向模型发送付费请求，不修改玩家卡。

## 更新结果（不持久化）

| 契约 | 必须发生 / 绝不能发生 | 出错代价 |
| --- | --- | --- |
| R1 | 数值保留真实前后值；数组与对象只展示真实变化，重复元素、嵌套、整容器替换都不能显示成不存在的改动 | 错误理解变量变化 |
| R2 | 当前提交的任意附加字段按操作索引展示，AI 的 old 不覆盖真实旧值；说明不执行、不写入聊天，切换目标或回滚后不复活 | 跨楼串说明、执行污染、存档膨胀 |
| R3 | 加载聊天时仅移除旧更新结果及所有 swipe 中的副本，操作历史、变量、检查点和其他插件数据保持不变 | 丢失回滚数据 |
| R4 | 重开聊天、删尾楼、切 swipe 后的历史结果由原执行点只读重建，查看不能改变量、规则、历史、检查点或触发保存 | 隐形状态污染、回滚错误 |

用隔离宿主与实际构建包核对当前说明、重开后的计算结果和保存文件；长数组与对象使用真实结果组件检查桌面及窄屏。

## swipe 取消后的入口恢复

| 契约 | 必须发生 / 绝不能发生 | 出错代价 |
| --- | --- | --- |
| S1 | 新 swipe 被快速停止或生成失败，宿主无消息渲染事件地恢复旧正文后，变量入口仍可用；恢复本身不能触发变量更新或额外保存，临时观察随恢复、切聊天或卸载结束 | 操作入口丢失、误结算或串聊天 |

用实际构建包在隔离聊天执行原生 swipe 与停止操作，覆盖末楼和旧楼；同一验收先复现旧包入口丢失，再检查修复后的恢复、重复操作和按钮可用性。
