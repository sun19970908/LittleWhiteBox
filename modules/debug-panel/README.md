# 运行日志与调试面板

`core/debug-core.js` 中的 `xbLog` 是主页面日志的唯一来源：模块加载后默认收集，默认保留最近 100 条，超出后淘汰最早记录。日志只驻留内存，不写入设置或数据库；刷新页面即丢弃，手动清空仍可用。

调试面板负责展示、性能监控和事件调试；关闭面板停止其监控，但不关闭或清空日志。主页面日志覆盖 console.warn/error、未捕获异常、未处理 Promise 拒绝，以及原有模块日志。普通 console.log/info 仍仅收集原有模块前缀，不等同于完整浏览器控制台。

`log-tool-contract.js` 定义助手只读工具 ReadLogs；`log-tool.js` 读取同一份 xbLog 快照。工具不受 JavaScript 执行开关控制，长结果复用助手当前运行内的结果分页。聊天 iframe 内部日志继续归 InspectPage 所有。日志跨聊天保留，不能仅凭当前角色判断某条日志的归属。

删除助手日志入口时，移除两个 log-tool 文件及助手中的注册、派发、分页和展示分支即可；无持久化数据需要迁移或清理。

## 验收契约

- 不打开调试面板时，主页面警告、错误、异常与模块日志必须可读；代价：错误证据丢失。
- 连续记录超过容量时，只保留最近记录，手动清空后继续收集，刷新后不恢复旧记录；代价：证据范围错误、长期内存增长。
- 反复开关调试面板不能停止收集、清空已有日志或重复挂载日志捕获；代价：证据丢失或重复。
- 助手禁用 JavaScript 执行时仍能调用 ReadLogs，将真实日志交给下一轮；读取不能修改日志或设置，长结果可完整续读；代价：权限错误、证据丢失。
- 捕获不能改变原有未处理异常处理器的返回值或普通 console 调用行为；代价：页面行为回归。
