# 场景地图二维空间改造

## 边界与终态

- 领域所有者仍为 `domains/map`，工具、Prompt、绘制与验收由 `apps/map` 拥有；不新增核心层注册或共享绘图框架。
- 唯一事实来源为现有 Map 分区。保留四个工具、当前 schema 和增量编辑；不迁移、不清空已有地图，不复制视觉样稿的候选数据结构。
- 朝向是元素的长期空间事实，跟随元素保存、修改和删除；新材质、图形标识也属于元素。纹理、装饰树冠、视口和绘制缓存只在内存中派生。
- 仅依赖现有 SVG/Vue/本地图标。删除仍是移除地图目录、既有注册与 Map 分区，没有新增外部资产或持久化实体。
- 世界图、剧情投影、触发时机、保存安全与更新通知不变。测试线不建立旧实现兼容壳；现有未携带新增可选字段的数据仍是合法当前数据。

## 执行顺序

1. 工具与领域增加可选 rotation（矩形/圆形中心顺时针旋转，0 ≤ angle < 360；省略保留，null 清除）；forest/glass 材质与 sofa/bridge 图形标识。错误朝向单项拒绝，提示可纠正。
2. 几何明确区分边界与面积：墙不填满，closed:false 保持开放；保留输入坐标、出口和通路，不自动布局或补门。
3. 拆分场景编排、几何投影、材质定义、物件绘制。所有材质细节均本地生成；不使用名称猜物件，不给点图标猜占地。常见物件独立组合类型、材质、占地和朝向。
4. 固定同一渲染器，以室内酒馆、自然溪谷、科幻舱室三组正式 Tool 输入编译、提交、读回后绘制。测试输入不能作为真实 Agent 生成质量的证明。
5. 浏览器检验窄屏、桌面、深浅主题、拖拽缩放、重进与128元素上限；运行自动检查并成套重建产物，不自动提交/推送。

## 绘制约束

- CSS、SVG、颜色、木纹、阴影、墙的视觉厚度不作为工具参数。
- 点图标保持示意；具有占地的已知物件使用俯视细节；陌生物件使用输入轮廓、材质与名称。
- 细节限制在占地内，极小尺寸简化；不生成杯子、人物、发现或其他额外事实。
- 林地装饰使用稳定种子、复用图形与区域裁剪，全场景不超过256个树冠；不按地图面积无限迭代。
- 去掉默认工程网格，保留显式网格元素；文字不随物件旋转，普通数据更新不重置视口。

## 验收

- 单元/集成：朝向输入、增量保留/清除、读取及存储；无效元素纠正；墙/路径语义；材质选择；装饰预算；移动人物不重排其他元素；旧地图不被改写。
- 浏览器：320px、390px、桌面，深浅主题；地图浏览零模型请求；保存安全及历史通知继续通过既有回归。
- 真实模型：仅使用独立测试聊天，不手调输出坐标、不为单张地图补专属代码。缺少可用测试环境或未执行时明确标记待验收，不拿手写数据代替。
- 检查：OS tests、vue-tsc、OS lint、imports、build、diff 与构建文件引用完整性。
