# 剧情规划

剧情规划会在你发送消息后、AI 写正文之前，先让另一个模型想好这一轮的剧情走向。规划显示在你的消息下方，你可以看、改、重来，满意了再点 `发送`，规划会跟着你的消息一起交给 AI 写正文。

## 启用功能

1. **扩展设置 → 小白X → 数据互动 → 勾选 `剧情规划`**（默认关闭）。
2. 点 `剧情规划` 旁边的设置按钮（悬停提示 `打开剧情规划设置`），打开剧情规划设置。没勾选时点它会提示 `请先启用剧情规划模块`。
3. 在 `API 配置` 里选一套**独立的** API 预设，并填好 `API Key`。剧情规划不能用酒馆当前的连接，原因和填法见 [剧情规划的特别要求](api-presets.md#剧情规划的特别要求)。
4. 回到 `快速开始`，确认 `启用规划器` 为 `开启`（默认开启），再点 `测试规划 API` 试一下。

设置面板右上角的 `状态` 显示 `已启用` / `未启用`；`保存` 显示 `就绪`、`保存中…`、`已保存`。你改的设置会自动保存，不需要另外点按钮。

## 一轮规划怎么走

1. 你像平时一样输入消息并发送。
2. 酒馆照常准备这一轮的上下文（角色卡、世界书、剧情记忆等）。
3. 你的消息下方出现规划框，先显示 `正在准备规划…`，再显示 `正在规划…`，规划内容会边生成边出现。
4. 生成完后，规划框里的文字可以直接修改。
5. 点 `发送`：规划追加到你这条消息末尾，AI 开始写正文。

规划框下方的按钮：

| 按钮 | 作用 |
| --- | --- |
| `停止规划` | 规划生成到一半时停下，已生成的部分保留，可以接着改或直接发送 |
| `重新规划` | 丢掉当前规划，重新生成一次 |
| `发送` | 采用规划框里的文字，开始生成正文 |
| `不操作` | 放弃这次规划，停止这一轮生成，规划框消失，你的消息保持原样 |

几点要知道的：

- 你不点任何按钮，规划框会一直留着，不会自动保存规划，也不会自动生成正文。
- 规划生成过程中你在框里打字，会自动停止规划，以你改的内容为准。
- 规划开始后，如果你在酒馆里点了停止生成，规划框仍保留；之后点 `发送` 会重新开始生成正文。
- 规划框只是临时预览，点 `发送` 前不会写进聊天记录。

## 什么时候不会规划

以下情况直接按原样发送，不出现规划框：

- `快速开始` 里 `启用规划器` 为 `关闭`。
- 消息为空，或以 `/` 开头（斜杠命令）。
- 消息里已经有 `<plot>` 标签。
- 同一条消息已经采用过规划，再次重新生成回复时。
- 继续生成、代写（impersonate）和后台静默生成。

## 设置面板

设置面板有五个标签：`快速开始`、`API 配置`、`提示词`、`上下文`、`调试`（手机上显示为 `开始`、`API`、`提示词`、`上下文`、`调试`）。

### 快速开始

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `启用规划器` | `开启` | 关闭后发送消息不再规划 |
| `合并连续 system` | `关闭` | 开启后，发给规划模型的相邻 system 消息合并成一条，不会跨过 user 消息。有些接口不接受连续多条 system 时打开 |

`快速测试` 里的 `测试规划 API` 会让规划模型回答一句话，用来确认预设可用。结果写进 `调试` 里的日志。

### API 配置

这里是共用的 API 预设编辑器，用法见 [API 预设](api-presets.md)。

### 提示词

规划模型会读到酒馆这一轮已经处理好的完整文字上下文，所以这里**不需要**再加世界书或剧情记忆，只写“怎么规划”的指令。

提示词由若干**提示词块**组成，每块有名称、角色（`system` 或 `user`）和内容：

- `system` 块按顺序放在最前面。
- 本轮上下文之后，依次接上所有 `user` 块，合成一条 user 消息。
- 块可以用 `↑` `↓` 调整顺序，`删除` 移除，`添加区块` 新增，`恢复默认` 换回内置提示词（会覆盖当前所有块）。
- 内容里可以用酒馆宏，如 `{{user}}`、`{{char}}`。用到 EJS 写法时，需要安装并启用“提示词模板”扩展。

`模板管理` 用来保存几套不同的提示词：

| 按钮 | 作用 |
| --- | --- |
| 下拉框 | 选一套模板，载入它的提示词块。内置模板叫 `Ena默认模板` |
| 💾 | 把当前提示词块存回选中的模板 |
| 📄 | 另存为新模板 |
| 🗑️ | 删除选中的模板，删除后可以点 `撤销` 找回 |

内置提示词要求规划模型输出 `<plot>`（剧情走向）和 `<note>`（写作注意事项）。

### 上下文

- `世界书`：规划沿用当前聊天的世界书和触发设置，要调整请去酒馆的世界书面板。
- `保留的规划输出标签（逗号分隔）`：规划结果只保留这些标签里的内容，默认 `plot, note, plot-log, state`。只能填英文标签名；留空表示不按标签过滤。回复里一个指定标签都没有时，保留整段回复。`<think>` / `<thinking>` 里的内容总是会被去掉。

### 调试

| 按钮 | 作用 |
| --- | --- |
| `查看本轮上下文` | 查看最近一次规划实际读到的上下文。还没在这个聊天里规划过时会提示先发送一条消息 |
| `诊断角色卡` | 检查当前角色卡能否被读到 |
| `测试规划 API` | 同快速开始里的测试 |

`日志` 记录每次测试规划的请求消息、原始回复和过滤后回复：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `持久化日志` | `是` | 选 `否` 时日志不保存 |
| `最大日志条数` | 20 | 1～200 |

还有 `刷新`、`导出 JSON`、`清空日志` 三个按钮。

## 失败时会看到什么

出错时会弹出提示，规划框里也会显示原因，可以点 `重新规划` 再试。

| 提示 | 原因与处理 |
| --- | --- |
| `剧情规划需要选择独立 API 预设，不能使用正在等待规划的酒馆连接。` | 选了 `沿用酒馆`，去 `API 配置` 换一套独立预设 |
| `剧情规划需要填写所选预设的 API Key` | 所选预设没有 Key，补上后保存 |
| `未生成有效的剧情规划，本次正文已停止。` | 规划模型返回空白（或只有思考内容）。检查模型和提示词，再点 `重新规划` |
| `本轮规划位置被其他提示词处理移除或复制，本次正文已停止。` | 其他扩展或提示词处理改动了你的消息，规划无处可放。暂时关掉可能冲突的扩展再试 |
| `聊天或用户消息已变化，本次剧情规划已取消。` | 规划期间切换了聊天、编辑或删除了这条消息，重新发送即可 |
| `剧情规划提示词使用了 EJS，请安装并启用“提示词模板”扩展后重试。` | 提示词里有 EJS 写法 |
| `请求超时` | 规划超过 3 分钟没完成，检查接口或换更快的模型 |
| `无法读取剧情规划配置，已禁止保存，请稍后重试` | 设置读取失败，刷新页面后再打开 |
| `保存超时` / `保存失败` | 设置没保存上，再改一次或重新打开设置面板 |

## 注意事项

- 规划要额外调用一次模型，每轮回复会多等一会儿，也会多花一份 token。
- 规划采用后是你这条消息的一部分，会随聊天保存，之后正文的 AI 也能看到。想删掉，编辑这条消息即可。
- 和变量 3.0 一起用时，规划在你点 `发送` 之后才参与结算，见 [变量 3.0](variables-v3.md)。

## 常见问题

### 发送后没有出现规划框

依次检查：扩展设置里 `剧情规划` 是否勾选；设置面板里 `启用规划器` 是否 `开启`；消息是否以 `/` 开头或已包含 `<plot>`。

### 规划框一直停在“正在准备规划…”

规划要等酒馆准备好上下文才开始。如果长时间不动，点 `不操作` 后重新发送；仍然不行，打开 [Log记录](tools.md#log记录查看某层楼发了什么) 或 [监控台](tools.md#监控台) 看看这一轮发生了什么。

### 能不能只看规划、不生成正文？

可以。看完不点 `发送` 就行；要彻底放弃，点 `不操作`。
