# 小白板

小白板是一张可视化的剧情地图。它根据当前角色卡和聊天内容生成世界设定、地图、地点和角色，你可以在地图上移动、和角色发短信、邀请角色见面，小白板会把这些行动和剧情资料交给正文的 AI。

面板标题旁的 `预测试` 角标是界面原样，表示这个功能还在试用中。

## 启用功能

1. **扩展设置 → 小白X → 数据互动 → 勾选 `小白板`**（默认关闭）。
2. 楼层消息上会多出一个地图图标按钮（悬停提示 `小白板`），点它打开面板。按钮被收进 X 按钮时，见 [X 按钮](tools.md#x-按钮收纳消息按钮)。
3. 默认用酒馆当前的连接生成。想换模型，在面板 `设置` → `连接` 里选预设，见 [API 预设](api-presets.md)。

面板可以拖动、缩放；手机上从底部弹出，可以拖动调整高度。右上角工具栏有 `生成`、`设置`、`切换主题` 和关闭（`✕`）。

## 快速开始

1. 打开面板，点工具栏的 `生成`。
2. 在 `世界生成` 弹窗里，按需填写 `玩家特殊需求（可选）`，例如 `希望有更多悬疑元素、增加一个神秘组织...`。
3. 点 `开始生成`，等待完成。看到 `生成成功` 后，世界、地图和角色就有了。
4. 到 `地图` 页点一个地点，选择前往；到 `通讯` 页和角色聊天。

## 两种运行模式

在 `设置` → `常规` → `运行模式` 选择，默认 `辅助模式 (Assist Mode)`。

| 模式 | 说明 |
| --- | --- |
| `故事模式 (Story Mode)` | 完整的世界模拟。生成分两步：先构思世界大纲（核心真相、层层揭开的秘密、时间线），再构建世界细节和地图 |
| `辅助模式 (Assist Mode)` | 只生成辅助用的地图和剧情，一步完成 |

## 三个页面

面板左侧切换 `世界`、`地图`、`通讯` 三页。

### 世界

| 区块 | 内容 |
| --- | --- |
| `最新消息` | 世界新闻。旁边的刷新按钮只重新生成新闻 |
| `当前状态` | 你现在的处境 |
| `行动指南` | 给你的行动建议 |

还没生成过时显示 `尚未生成世界数据...` 和 `等待世界生成...`。

### 地图

- 顶部下拉框切换视图：`🗺️ 大地图`、`📍 {地点}（你）`（你当前所在处）、其他已有局部地图的地点，以及 `── 隐藏地图 ──` 分组。
- 点地图上的地点，右侧显示信息卡，可以 `前往 {地点}`。
- 右侧 `场景描述` 显示当前位置的描述，可以 `刷新`。

**前往一个地点：**

1. 点地点 → `前往 {地点}`。
2. 在 `确认前往` 弹窗里，可以填 `任务目标（可选）`，例如你要去做什么。
3. 点 `确认前往`。

目标地点已有局部地图时直接过去；否则会先生成场景，可能顺带发现新的陌路人，并调整偏离分数。到达后，聊天里会以 `剧情任务` 的名义发一条消息，例如：

```text
{{user}}离开了家，来到旧书店。意图：打听失踪案的线索
```

有联络人已在那里等你时，会接一句“某某已经在这里等你了。”

### 快捷操作

地图页的浮动菜单（悬停提示 `快捷操作`）：

| 按钮 | 作用 |
| --- | --- |
| `局部地图` | 为当前位置生成室内或局部地图 |
| `世界推演` | 打开 `世界推演` 弹窗 |
| `局部剧情` | 为当前位置生成一段支线剧情，并以 `剧情任务` 的名义发到聊天里 |

已有局部地图的地点，`场景描述` 的 `刷新` 会重新生成这张局部地图。

### 通讯

角色分两组：

| 分组 | 说明 | 操作 |
| --- | --- | --- |
| `陌路人` | 剧情里遇到但还没建档的人 | `重要`、`背景板`：为他生成角色资料，写进角色卡绑定的世界书并移到联络人；`忽略`：移除 |
| `联络人` | 已建档的角色。当前角色卡本身也总在这里 | `短信`、`邀请` |

- 陌路人旁的刷新按钮（悬停提示 `微信摇一摇，寻找遇过的陌生人`）会从最近的聊天里找出新出现的人物。
- `重要` 生成的资料更详细，`背景板` 更简略。生成需要角色卡已经绑定世界书。
- 点 `+` 可以手动添加联络人：填 `UID（世界书条目UID）`（角色卡绑定世界书里的条目 UID），点 `检查`，在 `选择名字` 里选一个关键字作为名字，再点 `确定`。

**短信**

- 输入后按 Enter 发送，Shift+Enter 换行。对方回复时显示 `正在输入...`。
- 工具按钮：`压缩总结`（把较早的聊天压缩成摘要，至少要有 2 条未总结的消息）、`清空记录`、`回退`。
- 世界书联络人的短信记录保存在对应世界书条目里；角色卡联络人的短信记录保存在当前聊天里。

**邀请**

在 `邀请前往` 弹窗选一个地点，点 `发送邀请`。对方会回复接受或拒绝：

- `邀请成功`：如果你正好在那里，聊天里会发一条“某某过来了。”；否则对方会在那里等你，等你前往时一起出现。
- `邀请被拒`：显示对方的回复。

## 世界推演

世界不会一成不变。`世界推演` 会根据你的行动和时间流逝演化世界：`L1/L2 将大幅更新`、`L3/L4 适度调整`、`L5 保持不变`，`Stage 将推进到下一阶段`。

1. 地图页 `快捷操作` → `世界推演`。
2. 阅读提示 `⚠️ 此操作会覆盖当前世界数据，建议先备份`。需要的话，先在 `设置` → `数据` 里把数据复制出来。
3. 点 `开始推演`。

**推演提醒**：`推演倒计时` 每完成一次场景切换、局部地图或局部剧情就减 1，减到 0 时聊天里会提示 `该进行世界推演啦！`，`世界推演` 按钮也会高亮。推演或重新生成世界后，倒计时重新设为 3～7 之间的随机数。

## 小白板如何影响正文

小白板会在酒馆提示词里加入一段名为 `剧情地图` 的内容（位于角色描述之前），里面是你在 `设置` → `数据` 里勾选的资料。默认勾选 `大纲`、`世界资讯`、`大地图`、`局部地图`、`区域剧情`。世界真相会随 `当前阶段 (Stage)` 逐层揭开，并注明不可告知玩家。

你在酒馆的提示词管理里能看到 `剧情地图` 这一项。不想让正文读到某类资料，就在 `数据` 里取消勾选；全都不勾时这一项为空。关掉 `小白板` 总开关时它会被移除。

## 设置

工具栏 `设置` 打开，分 `常规`、`连接`、`数据` 三个标签，改完点 `保存设置`。

### 常规

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `运行模式` | `辅助模式 (Assist Mode)` | 见 [两种运行模式](#两种运行模式) |
| `当前阶段 (Stage)` | 0 | 0～10。决定世界真相揭开到第几层；生成世界时归 0，每次推演加 1 |
| `偏离分数 (Deviation)` | 0 | 0～100。剧情偏离原定走向的程度，场景切换时自动调整 |
| `推演倒计时 (Sim Countdown)` | 5 | 单位 `行动数`。数值 ≤ 0 时提醒推演 |
| `上下文楼层数` | 50 | 0～200。生成时读取最近多少楼聊天 |

### 连接

API 预设编辑器，见 [API 预设](api-presets.md)。

### 数据

- `NPC 生成设置`：生成联络人时写进世界书的 `插入位置`（`Char 前` / `Char 后` / `AN 前` / `AN 后` / `EM 前` / `EM 后`，默认 `Char 前`）和 `条目顺序`（默认 100）。
- `预设数据 (Presets)`：勾选哪些资料写入 `剧情地图`。每项都可以点 `编辑`，在 `编辑数据` 里直接改，有实时预览和格式检查。

| 数据块 | 默认 |
| --- | --- |
| `大纲`（核心真相、洋葱结构、时间线、用户指南） | 勾选 |
| `世界资讯` | 勾选 |
| `大地图` | 勾选 |
| `局部地图` | 勾选 |
| `区域剧情` | 勾选 |
| `角色卡短信` | 不勾选 |
| `陌路人` | 不勾选 |
| `联络人` | 不勾选 |

- `高级模板` → `编辑高级模板`：修改各项生成用的提示词和 JSON 格式，共 15 个模板（`短信回复`、`邀请回复`、`NPC 生成`、`重要NPC生成`、`提取陌路人`、`大纲生成`、`世界生成`、`世界推演（故事模式）`、`世界推演（辅助模式）`、`世界新闻刷新`、`场景切换`、`局部地图生成`、`局部地图刷新`、`局部剧情生成`、`总结压缩`）。可以 `通用保存`（所有角色卡共用）或 `角色卡保存`（只给当前角色卡），`重置` 恢复默认。优先级：角色卡 > 原保存 > 默认。

## 数据保存在哪里

- 世界、地图、阶段和倒计时按聊天保存，换聊天就是另一张地图。
- `重要` / `背景板` 生成的角色资料写进角色卡绑定的世界书。
- 运行模式、上下文楼层数和 NPC 生成设置对所有聊天生效。

## 失败时会看到什么

操作失败会弹出 `操作结果` 窗口，标题如 `生成失败`、`提取失败`、`邀请失败`，下方 `详细记录：` 里是具体原因。

| 提示 | 原因与处理 |
| --- | --- |
| `…失败：无法解析 JSON 数据` | 模型没按格式输出。重试，或换一个更守格式的模型 |
| `Step 1 失败：无法解析大纲数据，请重试` | 故事模式第一步失败，重新点 `开始生成` |
| `Step 2 失败：无法生成有效的地图` | 第二步失败。弹窗里会出现 `重试 Step2`，点它只重做第二步 |
| `Step 2 重试失败：缺少 Step 1 数据，请重新开始生成` | 第一步的结果已经丢失，重新生成 |
| `生成失败：返回数据缺少地图节点` | 辅助模式下模型没给出地点，重试 |
| `请先生成世界数据，再进行推演` | 还没生成世界 |
| `角色卡未绑定世界书，请先绑定世界书` | `重要` / `背景板` 需要角色卡绑定世界书 |
| `当前角色卡没有绑定世界书` / `在角色卡绑定的世界书中未找到 UID 为 … 的条目` | 添加联络人时检查 UID 和世界书 |
| `该条目没有主要关键字` | 这个世界书条目没填关键字，先在世界书里补上 |
| `该联络人已存在` | 已经添加过 |
| `至少需要2条未总结的消息才能压缩` | 多聊几句再压缩 |
| `生成回复失败，请调整重试` | 短信回复失败，重新发送 |

## 常见问题

### 楼层上没有地图按钮

确认 **扩展设置 → 小白X → 数据互动 → `小白板`** 已勾选；按钮也可能被收进了 X 按钮。

### 推演会把我手动改的数据覆盖掉吗？

会更新世界数据（大幅度改动 L1/L2 层）。推演前先在 `设置` → `数据` 里点 `编辑` 把重要内容复制出来。

### 正文 AI 没提到地图里的内容

检查 `设置` → `数据` 里对应数据块是否勾选，改完点 `保存设置`。
