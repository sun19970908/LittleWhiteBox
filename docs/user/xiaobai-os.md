# 小白 OS

小白 OS 是普通聊天里的一部“平板”，装着信息、地图、任务、钱包等应用。它跟着你当前的聊天走，让故事之外多一层可以玩、可以查、可以管理的东西。

## 启用功能

1. 打开 **扩展设置 → 小白X → 数据互动**，勾选 `小白 OS`。
2. 进入任意一个聊天，发送栏会出现 `小白 OS` 按钮。
3. 点这个按钮，弹出常用应用（排在前 6 位的应用），点一个直接打开；点 `打开桌面` 进入完整桌面。

没有进入聊天时打开会提示“请先进入聊天，再打开小白 OS。”。切换聊天时小白 OS 会自动关闭。开关失败会提示“切换小白 OS 失败”，并恢复原来的状态。

恢复默认时的开关状态见[默认开关](tools.md#默认开关)。

很多应用会调用模型，先在 [Agent API](#agent-api) 应用里配好模型。

## 桌面

- 点图标打开应用。
- 长按（手机）或按住拖动（电脑）图标可以整理顺序，顺序会自动保存；整理时可以点 `恢复默认`，完成后点 `完成`。
- 某个应用出错时只会显示这个应用的错误页，其他应用照常使用。

## 信息

和剧情里的人物发消息。点 `新的对话` 选联系人，在对话里发消息，对方会回复。

`信息设置` 里可以设置：`允许对方发图片`（默认关）、`允许对方发语音`（默认关）、`未写入主聊天时提醒`（默认开）。

私聊内容会同步到主聊天。没写进去时会提示“N 条消息已保留，尚未确认写入主聊天。”，点 `补到主聊天` 重试；重试不会再次发送消息或生成回复。点 `不再提示` 不会删除消息。

## 四次元壁

和角色背后的扮演者聊天，聊什么都不会影响主剧情。

| 设置 | 说明 |
| --- | --- |
| `带入的主聊天楼层数` | 让对方看到最近多少条主剧情，默认 20 |
| `流式生成` | 边生成边显示 |
| `允许对方发图片` / `允许对方发语音` | 允许对方在回复里配图、发语音，需要开启 [AI 画图](draw.md) / [语音](tts.md) |
| `实时吐槽` | 主剧情回复时，对方按 `吐槽概率`（默认 30%）随口吐槽 |
| `提示词模板` | 修改四次元壁的提示词，可以 `恢复默认` |

聊得多了，较早的聊天会被总结成“皮下记忆”，也可以点 `立即总结`。`皮下记忆` 可以直接查看和编辑。

`聊天记录` 里可以 `新建记录`、`重命名`、`删除记录`。清空皮下聊天时默认保留皮下记忆，勾选 `同时清空皮下记忆` 才会一起清掉。

## 管理员

管理员是 OS 的客服兼管理员。直接告诉它你遇到的情况，例如“这个任务明明完成了，为什么还在进行中”。它会读相关记录和聊天原文核实，确认后修正。

- 能修改的范围：任务（纠正进展、判定完成或失败）、地图（纠正地点、连接、人物位置、场景布局）、世界（概况、新闻和记录）。
- 能联网搜索和读取网页（需要配好联网，见 [小白助手的联网设置](assistant.md#联网)），也能只读查阅 OS 源码。
- 可以发图片（不超过 4MB 的 PNG、JPG、WEBP、GIF，模型需支持看图）。
- 它不会修改角色卡或世界书。

`清空聊天` 会删除管理员的聊天和附件，已经完成的修改不会撤销。

## 语伴

选一位角色当你的语言搭子：一起读文章、做练习、写作，语伴会批改并安排复习。

- 文章可以联网取材，也可以读语伴原创。没配联网时会提示，点 `读语伴原创` 即可开始。
- 练习写完点 `交给语伴 →` 评估，可以 `请语伴复核`。
- `学习概况` 里能看到知识点、到期复习和学习记录。
- 学习数据可以按语言删除，也可以全部清空，都会先确认。

## 地图

把世界设定画成地图，并跟随剧情更新。

| 视图 | 内容 |
| --- | --- |
| `世界图` | 所有地区 |
| `地区图` | 一个地区里的场景 |
| `场景图` | 一个地点的内部布局，可以切 `二维` / `三维` |

第一次点 `建立世界地图`，会根据角色和世界设定画图，设定没写的地方会合理补全。之后可以：

- 点 `更新地图` 根据最近的剧情补充。
- 在 `地图设置` 开启 `随对话自动更新`（默认关）：你发下一条消息时，根据上一轮对话更新地图，对所有普通聊天生效。
- `重新绘制` 会画一张新图，新图保存成功后才替换原图。
- 开启投影后，地图会显示在最后一条 AI 回复末尾。

查看地图不会改变你在故事里的位置。

## 世界

世界正在发生的事，以新闻的形式呈现。点 `获取新闻` 生成，`刷新新闻` 更新，都会调用模型。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `自动新闻` | 关 | 随剧情自动更新新闻，对所有聊天生效。关闭后保留已有新闻 |
| `作为剧情背景` | 开 | 把各聊天自己的世界近况提供给剧情 |

## 任务

| 页面 | 作用 |
| --- | --- |
| `发现` | 点 `获取委托` 生成一批委托，`换一批` 重新生成（都会调用模型）。点 `接下这份委托` 接取，报酬自动托管 |
| `我发布` | 点 `发布委托` 填写名称、目标、地点和报酬，报酬从钱包托管；然后 `开始招募` 并 `确认执行者` |
| `记录` | 已结束的委托 |

- 放弃接下的任务不再获得报酬，也不会扣你的小白币。
- 你发布的委托在结束前可以取消，托管报酬全额退回。
- 开启 `自动更新任务进展`（默认关）后，每次你发消息时会根据上一轮剧情更新任务；也可以手动点 `更新任务进展`。

## Dice

开启 `行动检定` 后，你尝试不确定的事时，由骰子而不是 AI 决定成败。

| 检定规则 | 说明 |
| --- | --- |
| `通用 D20` | 不需要人物数值，按情境定难度。可以选 `检定频率`：`标准`（只有成败会改变后续时才检定）或 `积极`（日常小目标也检定） |
| `D100 属性鉴定` | 用你的 `人物属性` 掷百分骰。属性全局保存，可 `一键随机`；`重置` 花费 100 小白币 |

开启 `随机遭遇` 后，剧情偶尔会出现意外：轻微 5%、中等 3%、重大 1%。触发后接下来两次发言不会再触发，不额外调用模型。

使用须知：

- 不要开启酒馆的「自动续写」。
- 使用不支持预填充的模型时，请关闭「续写预填充」，并保留预设「实用提示词」里的「继续推进」内容（不能为空）。
- 酒馆 1.14 / 1.15：点击检定的「继续」会发送输入框中尚未发送的文字。
- 功能开启期间，会自动创建「小白 OS · 行动检定显示」全局正则。

## 奇物商店

用小白币买奇物。买下的奇物放进 `背包`，不会立刻影响剧情；想好后在背包里使用。

- 使用后效果会影响之后的回复，已发生的剧情不会改写。
- 有的效果可以手动关闭，有的永久生效，使用前确认框会写明。
- `生效中` 可以查看和关闭正在起作用的效果。

## 钱包

显示小白币的 `可用余额` 和 `收支账单`，可以按 `全部` / `收入` / `支出` / `划转` 筛选。

钱包属于你这个酒馆用户，不分聊天：所有聊天共用一份余额。第一次使用会送 100 小白币。编辑、重新生成或删除主聊天消息，不会撤销已经发生的收支。

## 银行

| 产品 | 说明 |
| --- | --- |
| 定期存单 | 本金锁定到期，收益固定。提前支取会损失利息，确认后不可撤销 |
| 浮动理财 | 收益在区间内浮动，可能损失本金，到期前不能退出 |

每完成一条剧情回复，推进一回合。到期的资产可以点 `全部领取`，也会在下一次银行交易时一并结算到钱包。

## Agent API

和 [小白助手](assistant.md#api-配置) 共用主预设，在这里改了，助手里也会变。可以设置模型和 `联网渠道（全局）`。

点 `测试当前连接` 检查能否连通，成功会显示服务、模型和延迟。超时会提示“暂时没收到结果，请检查网络后重试。”。设置加载失败时点 `重新加载`。

## 数据保存

- 信息、地图、世界、四次元壁等内容跟着当前聊天保存。从聊天开出分支后，这些内容会保留，但钱包等经济资产不会复制，也不会再送开户礼。
- 钱包、银行、人物属性对所有聊天共用。
- 保存状态不确定时，应用会提示“还不确定…是否保存成功”，点 `检查保存`；服务器上的版本和本地不一致时，可以选 `使用已保存版本`。
- 在多台设备上同时操作小白 OS，可能互相覆盖。

## 注意事项

- 标着“将调用模型”的按钮会消耗额度。
- 自动更新类开关（地图、任务、世界新闻）对所有普通聊天生效。
- 小白酒馆里的手机是另一套应用，数据和这里不互通，见 [小白酒馆](tavern.md#手机)。

## 常见问题

### 发送栏里没有 `小白 OS` 按钮

确认 `总开关` 和 `小白 OS` 都已勾选，并且已经进入一个聊天。

### 应用提示“暂时无法打开”或显示错误页

点 `重试`。仍不行，关闭小白 OS 重新打开，或刷新页面。错误日志可以在 [监控台](tools.md#监控台) 查看。

### 提示“小白币余额不足”

去 [任务](#任务) 完成委托赚取小白币。
