# 小白酒馆

小白酒馆是一套全屏的角色扮演界面。长对话依然流畅；聊天背后还有一个后台助手，替你整理记忆、地图和人物状态，需要时可以翻到助手面板直接和它讨论剧情。角色卡、世界书、预设和正则都直接用酒馆本体里的。

## 启用功能

1. 打开 **扩展设置 → 小白X → 数据互动**，点 `小白酒馆` 按钮。
2. 首页点 `API 配置` 填好模型（见 [API 配置](#api-配置)）。
3. 回到首页点 `选择角色`，选一张角色卡开始聊天。之后再进来，这个按钮会变成 `继续聊天`。

小白酒馆需要 SillyTavern 1.14.0 或更高版本。版本过低时会提示“小白酒馆需要 SillyTavern 1.14.0 或更高版本。当前版本过低，其他小白 X 功能仍可正常使用。”`总开关` 关闭时按钮不可用。

## 首页

首页的快捷入口：

| 入口 | 作用 |
| --- | --- |
| `角色卡` | 浏览和查看角色卡、开场白、会话档案 |
| `世界书` | 编辑世界书 |
| `聊天预设` | 编辑和角色聊天时使用的预设 |
| `助手预设` | 编辑后台助手的规则，见 [助手预设](#助手预设) |
| `正则` | 编辑正则 |
| `API 配置` | 模型配置 |
| `基础设定` | 界面和聊天的基础设置 |
| `关于界面` | 小白酒馆的介绍 |

右上角可以切换白天/夜间，或 `退出` 回到酒馆。

## 聊天界面

聊天界面顶部有三个视图：

| 视图 | 内容 |
| --- | --- |
| `聊天` | 和角色的对话 |
| `助手` | 和后台助手的对话，以及它的工作记录 |
| `契约` | 设定后台助手可以做哪些事，见 [契约](#契约) |

侧边还有 `地图`、`记忆`、`档案` 面板，分别显示后台整理出的场景地图、记忆档案和人物状态。`收起面板` 把它们收起来。

### 和角色聊天

- 在输入框写下你的话，点 `发送`；生成中点 `停止`。
- 每层楼可以 `复制`、`编辑`；最后一轮可以 `重 roll 最后一轮`；也可以 `从这里删除后续剧情`。
- 较早的楼层折叠起来，点 `展开较早记录` 查看。

点 `聊天操作` 打开更多功能：

| 功能 | 说明 |
| --- | --- |
| `新建会话` | 和当前角色开一个新会话 |
| `会话档案` | 切换或删除这个角色的其他会话 |
| `对话分支` | 从某处开出分支 |
| `玩家便签` | 只对当前会话生效的作者注释，可设置插入位置（`主提示词后` / `主提示词前` / `聊天内 @ Depth`）、插入频率（0 禁用，1 每次，N 每 N 次用户输入）、是否参与世界书扫描 |
| `请求日志` | 查看真实发给模型的内容，见 [请求日志](#请求日志) |

### 和后台助手聊天

切到 `助手` 视图，输入框写“和助手说一句话...”。你可以让它梳理线索、讨论伏笔，不会打断剧情里的角色。

每轮对话后，助手会按 [契约](#契约) 自动维护记忆、状态栏和地图，状态显示在 `自动维护` 里，例如“正在更新记忆”“后台维护完成”。

| 状态 | 含义 |
| --- | --- |
| `后台维护失败` | 展开可查看原因，点 `重试` |
| `本次维护已作废` | 剧情在维护期间变了，旧结果没有采用，不需要处理 |
| `检查完成，没有需要更新的内容。` | 这轮没有要改的 |

## 契约

契约决定后台助手在故事里能做什么。打开 `契约`，勾选授权后点 `封存誓约`。默认全部开启。

| 授权 | 作用 |
| --- | --- |
| 记忆存档 | 维护、压缩和召回长期记忆 |
| 制图引擎 | 随剧情生成和更新地点、地标，显示在 `地图` 面板 |
| 角色档案 | 记录属性、状态、随身物品、人际关系，显示在 `档案` 面板 |
| 行动检定 | 你尝试不确定的事时，用真随机掷骰决定成败 |
| 随机遭遇 | 每隔一段时间，让世界发生一点意外 |

保存失败会提示“契约保存失败，请重试。”。记忆存档、制图和角色档案由后台助手执行，请在 [API 配置](#api-配置) 里配好分身 API。

## 手机

点 `打开手机` 打开一部故事里的手机，里面的应用：

| 应用 | 作用 |
| --- | --- |
| 信息 | 和剧情中出现的人物发消息 |
| 钱包 | 查看小白币余额和流水 |
| 任务 | 接取、发布委托，报酬由钱包托管 |
| 商店 | 用小白币买道具，放入背包，使用后影响之后的剧情 |
| 银行 | 定期存单、理财，以及骰局等小游戏 |
| 不明物 | 养一只神秘的小生物，可以喂食、聊天、改名 |

手机属于小白酒馆，和普通聊天里的 [小白 OS](xiaobai-os.md) 是两套独立的东西，数据不互通。切换会话时手机会自动收起。

使用前请留意确认框里的说明：

- 商店里部分道具生效后不能关闭，只能回滚到使用之前的剧情或删除会话来解除。
- 银行的理财可能损失本金，到期前不能退出；定期存单提前支取会扣除罚息。
- 让不明物离开会清空它的一切，已花的小白币不退。

## 设置

### API 配置

和 [小白助手](assistant.md#api-配置) 共用同一份配置。

- `主助手 API`：角色聊天使用。
- `分身 API`：后台维护记忆、地图、状态时使用。

### 助手预设

后台助手的规则。可以 `新增`、`导入`、`导出`、`改名`、`删除`；内置预设不能删除。点 `维护规则` 可以编辑三类规则：

| 标签 | 内容 |
| --- | --- |
| `全局记忆` | 全局状态的记录规则 |
| `人物记忆` | 人物长期状态的记录规则 |
| `状态栏` | 状态面板的结构和更新规则 |

### 基础设定

| 设置 | 说明 |
| --- | --- |
| `身份切换` | 选择聊天时使用哪个用户角色（身份与头像） |
| `楼层隐藏` | 只显示最近若干楼，其余隐藏 |
| `翻旧楼` | 每次加载多少楼 |
| `字体` | 聊天正文和输入框的字体与大小 |
| `上下文管理` | 当前不能调节：超过 20 楼时压缩，保留最近 10 楼；窗口外的内容交给记忆系统 |

## 请求日志

在 `聊天操作` 里打开：

- `上次调用`：上一次真实发出去的请求，可以切换 `美化` / `原始` 查看。
- `模拟发送`：写一句话点 `生成请求`，预览这句话会怎样发给模型，不会真的发送。

## 会话备份

会话、记忆、状态等数据保存在当前浏览器里。在 `角色卡` 详情里找到 `将角色卡会话档案从酒馆服务器备份、恢复`：

- `备份到酒馆服务器`：把这张角色卡的会话档案存到酒馆服务器。
- `从酒馆服务器恢复`：在其他浏览器或设备上恢复。

换设备或清理浏览器前，先备份。

## 注意事项

- 小白酒馆有自己的会话，和酒馆原生聊天记录不互通。
- 后台维护会额外调用分身 API，会消耗额度。

## 常见问题

### 点按钮后提示版本过低

把 SillyTavern 升级到 1.14.0 或更高。其他小白X功能不受影响。

### 角色卡列表提示“本地缓存在酒馆内未找到可用角色”

回到酒馆主界面加载一下角色，再点 `重新唤醒数据`。

### `档案` 面板显示“角色档案未授权”

在 [契约](#契约) 里开启“角色档案”。

### 后台一直没有更新记忆或地图

确认契约里开启了对应授权，`分身 API` 已配置；然后看 `助手` 视图里的 `自动维护` 状态。
