# 辅助工具

这一页介绍几样不直接参与剧情、但能帮你看清和整理酒馆的小工具：查看发给 AI 的完整内容、窄边框布局、消息按钮收纳、一键恢复默认、监控台、生成状态提示，以及插件更新。

## 消息日志与拦截

**扩展设置 → 小白X → 辅助工具 → 消息日志与拦截**

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| `Log记录` | 开 | 记住每次发给 AI 的请求，事后在对应楼层查看 |
| `Log拦截` | 关 | 先看看这次会发什么，**不真正发给 AI** |

两者都只对聊天补全（Chat Completion）类 API 生效。

### Log记录：查看某层楼发了什么

1. 勾选 `Log记录`。
2. 正常聊天，等 AI 回复。
3. 在这条 AI 回复的消息按钮里点便签图标（提示文字“查看历史API请求”）。
4. 弹出 **消息历史查看 - 第 N 条消息** 窗口。

- 只保留最近 10 次请求，切换聊天后清空，刷新页面也会清空。
- 找不到记录时会提示“未找到第 N 条消息的API请求记录”，通常是这层楼是在开启记录之前、刷新页面之前或很早以前生成的。

### Log拦截：只预览不发送

1. 勾选 `Log拦截`，发送按钮左边会多出一个便签图标（提示文字“预览消息”）。
2. 在输入框里写好消息。
3. 点这个图标。屏幕上提示“正在拦截请求...（30秒超时）”。
4. 弹出 **消息拦截** 窗口，显示本来要发给 AI 的全部内容，提示“拦截成功！”。

这次发送不会到达 AI，也不消耗额度；预览过程中临时出现在聊天里的楼层会被自动删掉。

**持续拦截**：长按这个图标约 1 秒，图标变红，提示“持续拦截已开启”。之后你每次正常发送、重新生成都会被拦截并弹出预览，回复位置显示“【小白X】已拦截消息”，随后自动清理。再长按 1 秒关闭，提示“持续拦截已关闭”。

### 预览窗口

| 区域 | 说明 |
| --- | --- |
| `美化` | 按身份分段、上色显示每条消息，最方便阅读 |
| `原始JSON` | 请求的原始内容 |
| `模拟后端` | 按已知规则推算酒馆后端最终会发出的格式，仅供参考 |
| 搜索框、`↑` `↓` | 搜索关键词并在结果间跳转，旁边显示“第几个/共几个”，没有结果显示 `无结果` |
| `关闭` | 关闭窗口 |

窗口可以拖动标题栏移动。

### 拦截失败时

| 提示 | 处理 |
| --- | --- |
| `消息拦截功能未启用` | 先勾选 `Log拦截` |
| `请先输入消息内容` | 输入框为空时无法预览 |
| `拦截失败: 等待超时 (30秒)` | 30 秒内没有发出请求。检查当前 API 是否为聊天补全，或是否有别的插件挡住了发送 |
| `拦截失败: …` / `拦截异常: …` | 按提示内容排查，必要时打开[监控台](#监控台)看日志 |

## 视觉增强

**扩展设置 → 小白X → 辅助工具 → 勾选 `沉浸布局显示(边框窄化)`**（默认关闭）

开启后：

- 聊天区边框和留白收窄，头像、名字、消息按钮重新排列，正文更宽。
- 默认进入 **锁定单回合**：只显示最后一条 AI 回复和它前面你的那条消息。
- 屏幕上最后两条消息的底部多出一排导航：

| 按钮 | 作用 |
| --- | --- |
| `<` | 切到上一个回复（左滑） |
| `\|切换：传统多楼层\|` / `\|切换：锁定单回合\|` | 在只看最后一回合和显示全部楼层之间切换，选择会被记住 |
| `n/m` `>` | 当前是第几个回复 / 共几个；点击切到下一个回复（右滑） |

- 滚动聊天时右侧会短暂出现 **回到顶部**、**回到底部** 两个按钮，停止滚动约 1.5 秒后自动隐藏。

关闭后布局立即恢复原样。

## X 按钮：收纳消息按钮

小白X的多个功能会在每条消息上加按钮（例如 Log 记录、剧情总结、小白板、变量面板）。为了不挤占消息按钮栏，它们被收进一个 **X** 形按钮里：点 X 展开，再点收起。

只有带这类按钮的消息才会出现 X。

**扩展设置 → 小白X → 渲染交互 → 功能说明 →** 点 `X按钮:右` / `X按钮:左` 切换 X 的位置：

| 按钮显示 | X 所在位置 |
| --- | --- |
| `X按钮:右`（默认） | 消息按钮栏右侧 |
| `X按钮:左` | 名字那一行，靠左 |

切换后对新出现的消息生效；想让已有楼层也换位置，刷新页面即可。

## 默认开关

**扩展设置 → 小白X → 渲染交互 → 功能说明 → 默认开关**

一键把小白X各功能开关恢复成初始状态，不需要确认：

| 恢复为开启 | 恢复为关闭 |
| --- | --- |
| 沉浸式模板、循环任务、变量管理、剧情总结、`Log记录`、生成状态追踪、小白 OS | `Log拦截`、沉浸布局、变量面板、小白板、剧情规划、豆包语音、`启用Blob渲染` |

AI 画图后端改为 **关闭**。

不会改动的内容：总开关、`渲染开关`、`渲染楼层`、变量系统版本、X 按钮位置，以及各功能内部的详细设置（模板、任务、API 配置等）。

## 监控台

监控台用来查看小白X的运行日志、事件和性能，遇到问题时先来这里看。

**扩展设置 → 小白X → 渲染交互 →** 点 `启用小白X` 旁边的 **监控** 按钮。按钮上的小灯亮起表示监控台已打开，再点一次关闭。

打开后屏幕上出现一个可拖动的 **监控** 小按钮，有错误时右上角显示错误数量。点它展开 **小白X 监控台** 窗口：

- `—`：缩回小按钮
- `×`：关闭监控台
- 电脑上可以拖动标题栏移动窗口，位置会被记住。

### 四个标签页

| 标签 | 内容 |
| --- | --- |
| `日志` | 运行日志。可按级别（全部 / INFO / WARN / ERROR）和模块筛选，`清空` 删除已有日志 |
| `事件` | `模块事件监听`：各功能正在监听哪些酒馆事件；`触发历史`：事件最近的触发记录，`清空历史` 可清除 |
| `缓存` | 各功能占用的缓存条数和大小，可查看 `详情`、单独 `清理` 或 `清理全部` |
| `性能` | 页面内存、消息数、图片数；`慢请求 (≥500ms)` 和 `长任务` 列表，各有 `清空` |

右上角 `刷新` 立即刷新当前数据。

### 日志保留规则

- 不打开监控台也会一直收集日志，打开后能看到之前的记录。
- 只保留最近 100 条，只存在内存里，**刷新页面就没了**。遇到问题请在刷新前查看或截图。
- 收集的是小白X自己的日志、页面上的警告和错误、未处理的异常，不等于浏览器控制台的全部内容。
- 关闭监控台只停止性能等监控，不会清空日志。

## 生成状态追踪

**扩展设置 → 小白X → 辅助工具 → 勾选 `生成状态追踪`**（默认开启，位于 `Log记录` / `Log拦截` 下方）

你发送消息、重新生成、切换回复或继续生成后，在 AI 开始输出第一个字之前，输入框的灰色提示文字会显示当前进行到哪一步和已等待的时间，例如：

```text
小白x记忆处理·3秒
```

常见阶段：

| 显示 | 含义 |
| --- | --- |
| `消息事件处理` | 酒馆正在处理你刚发出的消息 |
| `等待处理` | 正在准备发给 AI 的内容 |
| `小白x…处理` / `小白x…检查` | 小白X的某个功能正在工作，例如 `小白x绘图检查` |
| `小白x记忆处理` 及其细分步骤 | 剧情总结正在检索、整理记忆 |
| `等待回复` | 请求已发出，正在等 AI 回应 |

AI 开始输出、你停止生成或切换聊天后，提示自动恢复原样。如果 1 分钟内没有任何进展，提示也会自动消失，但生成本身不受影响。

使用非聊天补全 API 时，能显示的阶段会少一些。后台静默生成、自动触发的生成不会显示进度。

## 插件更新

小白X会在酒馆启动后自动检查更新。有新版本时：

- 扩展列表里 **小白X** 标题后面显示 `(有可用更新)`；
- 设置页 **总开关** 一栏出现一个云朵下载按钮。

点下载按钮即可更新：

| 提示 | 说明 |
| --- | --- |
| `小白X更新成功` | 约 1 秒后页面自动刷新，新版本生效 |
| `小白X已是最新版本` | 已经是最新，提示和按钮会消失 |
| `小白X更新失败` | 下方附带原因，例如 `无法确定 LittleWhiteBox 的安装位置`。可以稍后重试，或在酒馆的扩展管理里手动更新 |

## 常见问题

### 点了 `Log记录` 的便签图标没反应 / 找不到图标

- 确认 `Log记录` 已勾选，而且这是 AI 的回复（你自己的消息和开场白没有这个按钮）。
- 按钮可能被收进了 [X 按钮](#x-按钮收纳消息按钮)里，点 X 展开看看。

### 开关点了没反应

小白X总开关（`启用小白X`）关闭时，所有子功能的开关都不可操作。先打开总开关。

### 向别人求助时该提供什么

打开[监控台](#监控台)，在 `日志` 里把级别切到 `ERROR`，截图给对方；再配合 `Log记录` 查看出问题那层楼实际发给 AI 的内容。更多排查思路见[常见问题](faq.md)。
