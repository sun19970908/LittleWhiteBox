# 小白X 文档

小白X（LittleWhiteBox）是 SillyTavern 的多功能扩展：让聊天里的代码块变成可交互的界面，帮长篇剧情记住前情，管理角色状态和任务，给剧情配图、配音，还带有一套在酒馆里就能用的小白助手和应用。

这份文档随插件一起安装，内容与你当前使用的版本一致。

## 安装与更新

小白X 支持 SillyTavern 1.14 及以上版本。

1. 打开酒馆的 **扩展 → 安装扩展**。
2. 填入仓库地址 `https://github.com/RT15548/LittleWhiteBox`，点击安装。
3. 安装完成后刷新页面，在 **扩展设置** 里找到 **小白X**。

有新版本时，按酒馆扩展列表里的更新按钮更新即可。安装或更新失败，请看 [常见问题](faq.md)。

## 启用功能

打开 **扩展设置 → 小白X**，勾选最上方的 `总开关`。总开关关闭时，小白X 的所有功能都会停用。

设置分为四个竖排标签，各功能的开关在对应标签下：

| 标签 | 包含的功能 |
| --- | --- |
| 渲染交互 | 代码块渲染、沉浸式模板、功能文档入口 |
| 循环任务 | 循环任务的开关、任务列表与导入导出 |
| 数据互动 | 小白助手、小白 OS、小白电纸书、小白酒馆、剧情总结、小白板、剧情规划、变量管理与变量面板 |
| 辅助工具 | 消息日志与拦截、沉浸布局、AI 画图、语音 |

## 功能一览

### 渲染交互

| 功能 | 能做什么 |
| --- | --- |
| [代码块渲染](render.md) | 把消息里的 HTML 代码块渲染成可交互的界面，界面里可以调用酒馆命令 |
| [沉浸式模板](template.md) | 给角色设定固定版式，AI 只输出数据，小白X 填进模板显示 |
| [流式生成命令](streaming.md) | 用 `/xbgen` 在后台生成文本，并实时显示在界面里 |

### 剧情与记忆

| 功能 | 能做什么 |
| --- | --- |
| [剧情总结](story-summary.md) | 自动整理剧情、人物和事件，在长对话里帮 AI 想起前情 |
| [小白板](story-outline.md) | 可视化的剧情地图与大纲 |
| [剧情规划](ena-planner.md) | 发送前先规划这一轮剧情走向 |
| [API 预设](api-presets.md) | 以上功能共用的模型接口配置 |

### 变量与任务

| 功能 | 能做什么 |
| --- | --- |
| [变量系统](variables.md) | 记录生命值、背包、好感度等剧情状态；先在这里选用哪一版 |
| [变量 3.0](variables-v3.md) | 由卡定义规则，自动结算行动结果 |
| [变量 2.0](variables-v2.md) | 让 AI 在回复里按模板修改变量 |
| [循环任务](tasks.md) | 在指定时机自动执行斜杠命令或脚本 |

### 画图与语音

| 功能 | 能做什么 |
| --- | --- |
| [AI 画图](draw.md) | 用 NovelAI、SD WebUI 或 ComfyUI 为剧情配图 |
| [小白X 后端](server.md) | 让画图任务在酒馆服务器上继续，关掉页面也不中断 |
| [语音](tts.md) | 为角色消息配音 |

### 小白 agent

| 功能 | 能做什么 |
| --- | --- |
| [小白助手](assistant.md) | 在酒馆里陪你写卡、查问题、改配置 |
| [小白 OS](xiaobai-os.md) | 地图、通讯、钱包、游戏等剧情内应用 |
| [小白酒馆](tavern.md) | 小白X 的独立酒馆界面 |
| [小白电纸书](ebook.md) | 以阅读的方式浏览和续写故事 |

### 辅助工具

[辅助工具](tools.md) 介绍消息日志与拦截、沉浸布局、X 按钮、监控台等小工具。

### 给卡作者和脚本作者

| 接口 | 能做什么 |
| --- | --- |
| [画图与语音接口](media-api.md) | 在卡的界面里直接调用画图和语音 |
| [Agent 与联网接口](agent-api.md) | 在预设和任务脚本里复用小白X 的模型与联网配置 |

## 遇到问题

先看 [常见问题](faq.md)。仍然解决不了，可以打开 [小白助手](assistant.md)，把你看到的现象告诉它；也可以到 [GitHub](https://github.com/RT15548/LittleWhiteBox/issues) 反馈。
