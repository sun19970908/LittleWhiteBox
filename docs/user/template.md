# 沉浸式模板

沉浸式模板让你给一个角色准备一份固定的“版式”。AI 每次回复时只需要输出几项数据，小白X会把这些数据填进模板里，用模板代替原文显示在楼层中。AI 还在流式输出时，模板里的内容就会跟着实时更新。

常见用法：状态栏、角色卡片、信息面板，或者整楼都换成一张精美的 HTML 页面。

## 启用功能

**扩展设置 → 小白X → 渲染交互 → 勾选 `启用沉浸式模板`**（默认已勾选）

下方的 **当前角色模板设置** 会显示当前角色的状态：

| 显示 | 含义 |
| --- | --- |
| `请选择一个角色` | 还没打开任何角色的聊天 |
| `角色名 - 未设置模板` | 这个角色还没有模板 |
| `角色名 - 已启用模板功能` | 这个角色有模板，正在生效 |

点 **编辑模板** 打开模板编辑器。没有选择角色时会提示“请先选择一个角色”。

在 TauriTavern 托管聊天界面下，沉浸式模板不可用。

## 第一个模板：五分钟跑通

1. 打开一个角色的聊天，点 **编辑模板**。
2. 在 **模板内容** 里填：

   ```html
   <div style="border:1px solid #888;border-radius:8px;padding:10px">
     <b>[[地点]]</b> · [[时间]]
     <p>[[正文]]</p>
   </div>
   ```

3. 点 **保存**，看到提示“已保存 角色名 的模板设置”。
4. 让 AI 在回复里按下面的格式输出（可以写进角色卡或世界书的指令里）：

   ```text
   [地点]酒馆二楼[/地点]
   [时间]深夜[/时间]
   [正文]她推开门，灯光在走廊里摇晃。[/正文]
   ```

5. AI 回复后，这层楼就显示成模板的样子。

## 模板怎么写

模板里用 `[[变量名]]` 占位。显示时，每个占位会换成从 AI 回复里提取到的同名数据。

- 提取不到的变量显示为空。
- 数据是列表时，各项用 `, ` 连起来显示；是对象时显示成 JSON 文本。
- 模板可以是一段 HTML 片段，也可以是完整网页，两者的区别见[完整网页模板](#完整网页模板)。

## 怎么从回复里提取数据

小白X按下面的顺序尝试，**用第一种能取到数据的方式**：

| 顺序 | 回复里的写法 | 例子 |
| --- | --- | --- |
| 1 | 自定义正则（默认是 `[名]值[/名]`） | `[心情]开心[/心情]` |
| 2 | ```` ```json ```` 代码块 | 见下方 |
| 3 | 写在 XML 标签里的 JSON 或 YAML（标签可以还没闭合） | `<status>{"心情":"开心"}</status>` |
| 4 | 整条回复就是 JSON | `{"心情":"开心","好感":30}` |
| 5 | ```` ```yaml ```` 或 ```` ```yml ```` 代码块 | 见下方 |
| 6 | 整条回复就是 YAML | `mood: 开心` |

JSON 代码块示例：

````text
```json
{"心情": "开心", "好感": 30, "物品": ["钥匙", "地图"]}
```
````

YAML 代码块示例：

````text
```yaml
mood: 开心
favor: 30
```
````

流式输出时 JSON 往往还没写完，小白X会尽量读出已经完整的字段，所以模板能边生成边更新。

不用代码块、直接把整条回复（或标签里的内容）写成 YAML 时，至少要有一行键名是英文字母、数字或下划线，否则不会被当成 YAML。想全部用中文变量名，请用 `[名]值[/名]` 或 JSON 写法。

## 模板编辑器

### 自定义正则表达式

决定第 1 种提取方式。默认值是：

```text
\[([^\]]+)\]([\s\S]*?)\[\/\1\]
```

规则：正则的**第 1 个括号**是变量名，**第 2 个括号**是变量值，值的首尾空白会被去掉。也可以写成 `/正则/标志` 的形式。正则写错时会自动退回默认值。

例如想让 AI 用 `<<名|值>>` 输出：

```text
<<([^|>]+)\|([\s\S]*?)>>
```

### 文本不使用插件预设的正则及格式解析器

勾选后不再提取任何数据：模板里**每一个** `[[变量名]]` 都会被换成**整条回复的全文**。适合只想给整条回复套一个外框的情况：

```html
<div class="my-frame">[[text]]</div>
```

### 消息范围限制

| 选项 | 说明 |
| --- | --- |
| `首条消息不插入模板` | 开场白（第一层楼）保持原样 |
| `仅在最后几条消息中生效` | 只有最近若干层楼套用模板，更早的楼层恢复原文 |
| `消息数量:` | 配合上一项使用，1–50，默认 5 |

整楼使用完整网页模板时，勾选 `仅在最后几条消息中生效` 可以减少同时运行的网页数量，聊天更流畅。

### 模板内容

就是上文说的模板。点 **保存** 后立即对当前聊天里已有的楼层重新套用；点 **取消** 则不保存。

### 导入和导出

编辑器顶部的 **导出模板** 会下载当前填写的模板及其设置；**导入模板** 会把 JSON 文件中的内容填入编辑器。导入后点 **保存** 才会写进当前角色卡，点 **取消** 则保留原模板。

## 哪些楼层会套用模板

- 只处理 AI 的回复；你的消息和系统消息不处理。
- 只对当前打开的角色生效，模板保存在这个角色上。
- 只改变显示，不改聊天记录里的原文。编辑这层楼时，你看到和修改的仍是原文；保存或取消编辑后，模板会重新套用。
- 切换回复（swipe）、编辑、切换聊天或角色后，会自动重新套用。

## 完整网页模板

模板里含有 `<html`、`<!DOCTYPE` 或 `<script` 时，这层楼会被渲染成一个独立的小网页，和[代码块渲染](render.md#网页里可以用的函数)一样可以使用 `STscript`、`callGenerate`、头像样式等函数。

生成过程中，小白X会把新数据推给网页，网页里的占位内容直接更新，不会整页刷新。

### 模板网页里的额外函数

| 名字 | 作用 |
| --- | --- |
| `updateTemplateVariables(变量)` | 把变量写进所有带 `data-xiaobaix-var="变量名"` 的元素。每次数据更新时小白X会自动调用它 |
| `loadExternalPage(网址, 挂载点, 选项)` | 把另一个网页加载进当前网页的某个元素里 |

每个 `[[变量名]]` 实际会变成一个带 `data-xiaobaix-var` 的元素，所以自动更新对它们直接生效。数据更新后，网页会收到一个 `contentUpdated` 事件，你可以在这里做自己的刷新：

```html
<div>好感：[[好感]]</div>
<div id="bar" style="height:8px;background:#e66"></div>
<script>
  window.addEventListener('contentUpdated', () => {
    const v = Number(document.querySelector('[data-xiaobaix-var="好感"]').textContent) || 0;
    document.getElementById('bar').style.width = Math.min(100, v) + '%';
  });
</script>
```

`loadExternalPage` 用法：

```html
<div id="game"></div>
<script>
  loadExternalPage('https://example.com/game.html', 'game', { minHeight: '600px' });
</script>
```

- 第二个参数可以是元素的 id，也可以直接传元素。找不到时以 `mount not found` 失败。
- `minHeight` 是 CSS 高度值，默认 `800px`。
- 能读取到网页内容时，嵌入的网页里也能用 `STscript`；读取不到时改为直接嵌入网址，此时没有 `STscript`。
- 不接受 `javascript:` 这类网址。

## 模板跟着角色卡走

模板保存在角色卡里。导出、分享角色卡时，模板会一起带走；别人导入这张卡、打开沉浸式模板后就能直接使用，不需要单独导入模板文件。

## 注意事项

- 关闭 `启用沉浸式模板` 后，所有楼层立即恢复显示原文，模板本身不会被删除。
- 小白X总开关关闭时，模板也会停用。
- 完整网页模板与代码块渲染一样没有沙箱，只使用你信任的角色卡。

## 常见问题

### 保存了模板，但楼层没有变化

- 确认 `启用沉浸式模板` 已勾选，状态显示 `角色名 - 已启用模板功能`。
- 确认这层楼是 AI 回复，而且不在被 `首条消息不插入模板`、`仅在最后几条消息中生效` 排除的范围。
- 检查 AI 的输出格式是否和[提取方式](#怎么从回复里提取数据)对得上，特别是变量名要和模板里的 `[[变量名]]` 一字不差。

### 模板显示了，但某些位置是空的

这个变量没有被提取到。最常见的原因是回复里同时有多种格式：小白X只采用第一种能取到数据的方式，比如回复里有一个 `[名]值[/名]`，后面的 JSON 就不会再读。让 AI 统一用一种格式输出。

### 模板网页显示异常

打开[监控台](tools.md#监控台)查看报错。模板网页的高度会随内容自动调整，写死 `100vh` 的高度会被改成按内容撑开（最少 600 像素）。
