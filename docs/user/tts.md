# 语音

语音功能把 AI 的回复读出来。你可以直接用免费的试用音色，也可以接入自己的火山引擎（豆包语音）账号，用上 200 多个音色、情感控制和你自己复刻的声音。

想在自己写的卡片里调用语音，见[画图与语音接口](media-api.md)。

## 开始前：开启 CORS 代理

鉴权音色要经过酒馆转发请求，需要先打开酒馆的 CORS 代理：

1. 用文本编辑器打开酒馆目录下的 `config.yaml`。
2. 把 `enableCorsProxy` 改成：

   ```text
   enableCorsProxy: true
   ```

3. 重启酒馆。要重启酒馆的进程或容器，不是在浏览器里按 F5 刷新。

只用试用音色时不需要这一步，但建议一起开好，之后换鉴权音色就不用再重启。

## 启用语音

1. 打开 **扩展设置 → 小白X → 辅助工具 → 豆包 语音**。
2. 勾选 `启用 TTS 语音`。
3. 点 `语音设置` 打开设置面板。

没勾选 `启用 TTS 语音` 就点 `语音设置`，会提示“请先启用 TTS 语音模块”。

启用后，每条 AI 回复上会出现一个播放器。默认 AI 回复完会自动朗读，用的是试用音色“晓晓”。

## 试用和鉴权

| | 试用音色 | 鉴权音色 |
| --- | --- | --- |
| 需要配置 | 不需要 | 火山引擎的 AppID 和 Access Token |
| 音色数量 | 21 个 | 200 多个，另外可以用复刻音色 |
| 情感 | 支持 | 支持 |
| 语气提示 | 不支持 | 支持（仅 2.0 音色） |
| 费用 | 免费 | 按火山引擎的计费 |

两种可以混用：一条回复里不同段落用不同的音色，试用和鉴权都行。

试用音色有：晓晓、晓伊、小北、小妮（普通话女声），云希、云健、云扬、云夏（普通话男声），曉佳、曉曼、雲龍（粤语），曉臻、曉雨、雲哲（台湾腔），Jenny、Aria、Sonia、Guy、Ryan（英语），七海、圭太（日语）。

## 设置面板

面板顶部的 `楼层` 和 `悬浮` 控制在哪里显示播放器（见[播放器](#播放器)）。左侧（手机上是底部）有五页。

### 基础配置

**鉴权配置（可选）**：填 `AppID` 和 `Access Token`，状态从 `未配置` 变成 `已配置`。获取方法见[开通火山引擎](#开通火山引擎)。

**朗读设置**

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `AI 回复后自动朗读` | 开 | AI 每次回复完自动读这条 |
| `语速` | `1.0x` | 0.5–2.0 倍 |

**文本过滤**：决定读哪些、不读哪些，见[只读想听的部分](#只读想听的部分)。

改完点 `保存配置`。

### 音色管理

这里管理“我的音色”。播放时用的默认音色、播放器里能选的音色，都来自“我的音色”。

1. 在 `试用` 或 `预设库` 标签里找一个音色，可以选一句测试文本点 `试听`。
2. 把它加入 `我的` 标签，可以给它起个名字，例如“小白”。这个名字之后可以在[配音指令](#配音指令)里用。
3. 在 `我的` 里点一个音色，把它设为默认。
4. 点 `保存音色设置`。

`预设库` 是鉴权音色，没配置鉴权时会提示先去基础配置设置。预设库可以按性别、模型（2.0 / 1.0）、语种、场景筛选。

**复刻音色**：在火山引擎复刻好声音后，拿到 `S_` 开头的音色 ID，在 `手动添加复刻音色` 里填音色 ID、名称，选复刻版本（`复刻 2.0` 或 `复刻 1.0`），点 `添加到我的音色`。

### 高级设置

这些选项只对鉴权音色生效，一般保持默认就行。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `返回计费用量（text_words）` | 关 | 让火山引擎在结果里附带这次的计费字数 |
| `启用火山服务端缓存` | 关 | 让火山那边缓存相同的合成请求 |
| `启用 Markdown 过滤` | 开 | 不读 Markdown 符号 |
| `启用 1.1 模型（仅对 seed-tts-1.0 生效）` | 开 | 1.0 音色使用 1.1 模型 |
| `不过滤 Emoji` | 关 | 开启后会尝试读出表情符号 |
| `启用自动语种识别` | 关 | 让火山自动判断语种 |
| `指定语种` | 空 | 手动指定语种 |
| `括号过滤长度` | 100 | 括号里的内容不超过这个长度时跳过不读 |
| `音高调整` | 0 | 调高或调低音高 |

改完点 `保存高级设置`。

### 缓存管理

合成过的语音会存在你这台设备的浏览器里，同样的内容再播放时直接用缓存，不用重新合成，也不重复计费。

这里能看到缓存条数、占用空间、命中和未命中次数。`缓存天数`、`最大条数`、`最大容量 (MB)` 默认是 7 天、200 条、200 MB，超出时自动清理旧的。`清理过期` 立即清掉过期的，`清空全部` 清掉所有缓存。

### 使用说明

面板里自带配音指令写法、情感列表和开通教程，随时可以查。

## 播放器

### 楼层播放器

每条 AI 回复左侧有一个小播放器：

| 状态 | 含义 |
| --- | --- |
| `播放` | 还没开始，点一下开始读 |
| `准备` / `1/3` | 正在合成；分段时显示读到第几段 |
| `缓存` | 用的是缓存 |
| `暂停` | 已暂停，再点继续 |
| `完成` | 读完了，点一下重新读 |
| `受阻` | 浏览器不让自动播放声音，点一下就能播 |
| 错误文字 | 合成或播放失败，显示简短原因，点一下重试 |

- 正在合成时点一下是取消；正在播放时点一下是暂停或继续。
- 播放时可以拖动进度条跳到想听的位置。
- 展开菜单能看到这条要读多少字，还可以临时改 `音色`（只列出“我的音色”）和 `语速`、开关 `自动朗读`，点齿轮打开设置面板。这些改动会直接保存。

### 悬浮播放器

在设置面板顶部勾选 `悬浮`（默认不勾）后，页面上会出现一个可以拖到任意位置的播放器。它总是读**最后一条 AI 回复**；聊天里没有 AI 回复时会提示“没有可朗读的AI消息”。

## 只读想听的部分

**基础配置 → 文本过滤** 里有两种规则，都是填“起始”和“结束”两段文字：

- **跳过区间**：遇到起始后跳过，直到结束。例如起始填 `<状态栏>`、结束填 `</状态栏>`，状态栏就不读。
- **只读区间**：勾选 `启用只读区间（仅朗读匹配内容）` 后，只读起始和结束之间的内容，其他都不读。例如起始填 `「`、结束填 `」`，就只读对白。没有匹配到任何内容时，这条回复不读。

起始或结束都可以单独留空：

| 写法 | 跳过区间 | 只读区间 |
| --- | --- | --- |
| 起始和结束都填 | 跳过两者之间 | 只读两者之间 |
| 只填起始 | 从起始开始，后面全部不读 | 从起始开始读到最后 |
| 只填结束 | 结束之前全部不读 | 只读开头到结束这一段 |

另外，你自己发的消息永远不读。

## 配音指令

让 AI 在回复里写配音指令，就能给不同段落换音色、加情感。格式是：

```text
[tts:speaker=音色名;emotion=情绪;context=语气提示]
```

把它放在要读的那段话前面一行，例如：

```text
[tts:speaker=小白;emotion=开心]
今天天气真好，我们出去玩吧！
[tts:speaker=旁白;emotion=自然讲述]
她拉着你的手跑出了门。
```

- 三个参数顺序随意，用 `;` 隔开，不需要的可以不写。
- 每遇到一个新的 `[tts:...]` 就开始新的一段，按顺序播放。每段只用自己写的参数，不会继承上一段。
- 没写 `speaker` 的段落用默认音色。
- 指令在聊天里显示成一个小标签，鼠标停上去能看到参数。

**音色（speaker）**：写你在“我的音色”里起的名字，例如 `speaker=小白`。名字对不上时用默认音色。

**情感（emotion）**：中文或英文都行。

| 中文 | 英文 |
| --- | --- |
| 开心、悲伤、生气、惊讶、恐惧、厌恶、激动、冷漠、中性、沮丧 | happy、sad、angry、surprised、fear、hate、excited、coldness、neutral、depressed |
| 撒娇、害羞、安慰、鼓励、咆哮、焦急、温柔 | lovey-dovey、shy、comfort、tension、tender |
| 讲故事、自然讲述、情感电台、磁性、广告营销、气泡音、低语 | storytelling、radio、magnetic、advertising、vocal-fry、asmr |
| 新闻播报、娱乐八卦、方言、对话、闲聊、温暖、深情、权威 | news、entertainment、dialect、chat、warm、affectionate、authoritative |

写了不认识的情感会被忽略，照常朗读。

**语气提示（context）**：用一句话描述语气，例如 `context=用更委屈的语气`、`context=放慢一点，压低音量`。只对 2.0 鉴权音色生效。

你可以把这些写法放进角色卡或预设，让 AI 自己给台词配上音色和情感。

## 语音气泡

AI 在正文里写 `[voice:情绪:要读的话]`（也可以写 `[语音:...]`），会显示成一个聊天软件那样的语音气泡，点一下就播放。情绪可以省略，写成 `[voice:要读的话]`。例如：

```text
她发来一条语音：[voice:开心:晚上一起吃饭吧！]
```

气泡用默认音色播放，不受自动朗读影响。没启用语音时，气泡点了没反应，会闪一下红色。

## 开通火山引擎

想用鉴权音色或复刻音色时：

1. 按[开始前](#开始前开启-cors-代理)开启 CORS 代理。
2. 在火山引擎开通语音服务（推荐一次性全部开通）：<https://console.volcengine.com/speech/new/setting/activate>
3. 获取 AppID 和 Access Token：<https://console.volcengine.com/speech/service/8>
4. 回到 **基础配置 → 鉴权配置（可选）** 填好，点 `保存配置`。
5. 到 `音色管理` 的 `预设库` 挑音色，加入“我的音色”。

想复刻自己的声音，在这里录制：<https://console.volcengine.com/speech/new/experience/clone>。复刻完成后去音色库拿到 `S_` 开头的 ID，再按[音色管理](#音色管理)添加。

## 常见问题

**AI 回复了但没有自动读**

- 检查 `AI 回复后自动朗读` 或播放器菜单里的 `自动朗读` 是否开着。
- 检查[文本过滤](#只读想听的部分)是不是把整条回复都过滤掉了，尤其是开了只读区间、但回复里没有匹配的内容。
- 播放器显示 `受阻`：浏览器拦住了自动播放，点一下播放器就能播。

**播放器显示“TTS HTTP …”或“TTS 合成失败”**

试用音色的服务暂时不可用。稍后再试，或换成鉴权音色。

**播放器显示“V3 请求失败: 404 …”**

多半是 CORS 代理没开。按[开始前](#开始前开启-cors-代理)开启并重启酒馆。

**播放器显示“V3 请求失败: 401 …”或 403**

AppID 或 Access Token 不对，或者对应的服务还没开通。到火山引擎控制台核对，并确认已开通要用的音色。

**提示“部分音色需要配置鉴权 API，将仅播放免费音色”**

回复里用到了鉴权音色，但你还没配置鉴权，所以只读用试用音色的段落。全部段落都要鉴权时，播放器显示“所有音色均需要鉴权”。配置鉴权，或把默认音色换成试用音色。

**试听时提示“请先配置鉴权 API”**

`预设库` 里的音色要先配置鉴权才能试听。

**配音指令里写了 speaker 但没换音色**

`speaker` 要写“我的音色”里的名字，大小写和字都要完全一致，并且已经点了 `保存音色设置`。

**提示“无法读取 TTS 配置，已禁止保存，请稍后重试”**

设置还没加载好，为了不覆盖你原来的配置暂时不允许保存。刷新页面后再试。
