# API 预设

剧情总结、剧情规划、小白板这三个功能要调用模型。API 预设就是一套套命名好的“接口 + 模型 + 参数”配置，三个功能共用同一份预设列表，各自选用其中一套。你可以让三个功能都沿用酒馆当前的连接，也可以给某个功能单独配一个便宜或更快的模型。

## 在哪里设置

预设编辑器挂在三个功能各自的设置里，打开哪一处都是同一份列表：

| 功能 | 打开位置 |
| --- | --- |
| [剧情总结](story-summary.md) | 剧情总结面板 → 右上角 `设置` → `模型连接` |
| [剧情规划](ena-planner.md) | 剧情规划设置 → `API 配置` |
| [小白板](story-outline.md) | 小白板面板 → `设置` → `连接` |

在某一处新增、修改或删除的预设，另外两处也能看到并选用。**每个功能选用哪一套，是分开记的**：在剧情总结里切换预设，不会改变剧情规划正在用的那套。

## 第一次打开时的样子

| 功能 | 默认选用 |
| --- | --- |
| 剧情总结 | 预设 `默认1`（渠道为 `沿用酒馆`） |
| 小白板 | `沿用酒馆` |
| 剧情规划 | `未选择预设`，需要你先选一套带 API Key 的预设 |

如果你以前在这三个功能里分别填过接口，第一次打开时会自动整理成预设：剧情总结的旧配置变成 `默认1`，剧情规划的变成 `默认2`，小白板的变成 `默认3`，并分别绑定回原来的功能，不用重新填。

## 选择预设

编辑器顶部是预设下拉框，后面跟四个按钮：`新增预设`、`重命名预设`、`保存预设`、`删除预设`。

下拉框里固定有一项 `沿用酒馆`，其余是你保存过的预设：

- **`沿用酒馆`**：直接使用酒馆当前的 API 连接和模型，什么都不用填。选中后只显示 `测试连接` 按钮。
- **某个预设**：使用这套预设里填的接口和模型。

在下拉框里切换，会立刻改成本功能使用这一套，不需要再点保存。

## 新建和编辑预设

1. 点 `新增预设`，输入 `预设名称`。新预设会复制当前选中那套的内容，并自动成为本功能正在用的预设。
2. 选 `渠道`，按下表填写对应字段。
3. 填好 `Model`。不知道模型名时，点 `拉取模型`，成功后会显示“N 个模型”，从下拉框里选一个；也可以保持 `手动填写` 自己输入。
4. 点 `测试连接`。看到 `生成测试成功` 就说明能用。
5. 点 `保存预设`。显示 `已保存` 才算保存完成。

> 改了字段但没点 `保存预设`，换预设或关掉面板后修改不会保留。

### 渠道

| 渠道 | 说明 |
| --- | --- |
| `沿用酒馆` | 用酒馆当前连接生成，不需要地址和 Key |
| `OpenAI Responses` | OpenAI Responses 接口 |
| `OpenAI 兼容` | 大多数中转站、本地服务使用的 OpenAI 兼容接口，由浏览器直接请求 |
| `酒馆 OpenAI 兼容` | 同样是 OpenAI 兼容接口，但请求经由酒馆后端转发 |
| `酒馆 Claude` | 经由酒馆后端请求 Claude 接口 |
| `酒馆 Google AI` | 经由酒馆后端请求 Google AI（Gemini）接口 |
| `Anthropic` | 浏览器直接请求 Anthropic 接口 |
| `Google AI` | 浏览器直接请求 Google AI（Gemini）接口 |
| `Google Vertex AI` | Google Cloud Vertex AI，见下方 [Google Vertex AI](#google-vertex-ai) |

如果中转站不允许浏览器直接访问（请求被跨域拦截），可以改用名字带“酒馆”的渠道。

### 连接字段

| 字段 | 说明 |
| --- | --- |
| `Base URL` | 接口地址 |
| `路径前缀` | `自动`：按渠道补全接口路径；`自定义`：自己填写前缀 |
| `API Key` | 密钥，默认隐藏，点 `显示` / `隐藏` 切换 |
| `Model` | 模型名称 |
| `模型列表鉴权` | 只有 Anthropic、Google 类渠道出现。拉取模型列表时 Key 放在哪个请求头：`x-api-key` / `Bearer`（Google 类为 `Google API Key` / `Bearer`）。拉不到模型时可以换一个试试 |

### Google Vertex AI

选 `Google Vertex AI` 后会多出 `连接方式`：

| 连接方式 | 需要填写 |
| --- | --- |
| `中转（地址 + API Key）` | `Base URL`、`API Key`（默认方式） |
| `服务账号 JSON（Google Cloud 项目）` | 点 `选择 JSON 文件` 导入 Google 下载的服务账号 JSON；`项目 ID` 可以留空，使用 JSON 里的项目；`区域` 默认 `global` |
| `API Key（Express）` | Vertex Express 的 API Key |

服务账号方式需要用 HTTPS 或 localhost 打开酒馆，否则会提示 `服务账号认证需要 HTTPS 或 localhost，以及支持 Web Crypto 的浏览器。`

### 生成参数

展开 `生成参数` 可以调这些项。留空表示不发送，由接口使用默认值：

| 参数 | 说明 |
| --- | --- |
| `流式输出` | 默认开启 |
| `Temperature` | 温度（Vertex 不显示） |
| `最大输出 Token` | 单次回复长度上限 |
| `Top P` / `Top K` / `频率惩罚` / `存在惩罚` / `重复惩罚` | 只显示当前渠道实际支持的项 |
| `Reasoning 模式` | `跟随模型默认` / `开启` / `关闭`。选 `开启` 后，模型支持时会出现 `思考强度` 或 `思考 Token 预算` |

## 重命名与删除

- `重命名预设`：改名不影响哪些功能在用它。
- `删除预设`：会先确认，并告诉你哪些功能正在用它、删除后改用哪一套，例如：

  ```text
  删除预设“中转A”？
  剧情总结、小白板将使用“默认1”。
  ```

  正在使用它的功能会自动改用列表里相邻的那一套。
- 至少要保留一套预设，只剩一套时不能删除。

## 剧情规划的特别要求

剧情规划在酒馆准备发送正文的同时就要调用模型，所以**不能使用酒馆当前的连接**：

- 选 `沿用酒馆`，或者选了渠道为 `沿用酒馆` 的预设，发送时会提示 `剧情规划需要选择独立 API 预设，不能使用正在等待规划的酒馆连接。`
- 除 Vertex 外，预设必须填 `API Key`。编辑器里会一直提示 `剧情规划需要填写所选预设的 API Key`，直到你填上。

## 常见提示

| 提示 | 原因与处理 |
| --- | --- |
| `请输入预设名称` | 名称为空，重新输入 |
| `已存在同名预设` | 换一个名字 |
| `至少要保留一套预设` | 只剩一套时不能删除 |
| `预设不存在，请重新选择` / `未选择预设` | 该功能绑定的预设已不存在或还没选，在下拉框里重新选一套 |
| `请填写 API 地址` | 填写 `Base URL` |
| `请填写模型名称` | 填写 `Model` |
| `接口未返回正文` | 接口连通了但没返回文字，检查模型名、额度或换个模型 |
| `请求超时` | 等待太久没有回应，检查网络、地址或稍后重试 |
| `配置尚未加载，请重试` / 加载失败 | 点编辑器里的 `重试` |
| `API 预设保存失败` | 保存没有成功，重新点 `保存预设` |
| `酒馆生成模块尚未加载` | 酒馆还没准备好，稍等或刷新页面 |

接口返回的错误会原样显示，其中的 API Key 会被替换成 `[redacted]`，截图求助时不必担心泄露。

## 常见问题

### 三个功能能用不同的模型吗？

能。每个功能分别选自己的预设，互不影响。

### 改了预设内容，其它功能会跟着变吗？

会。几个功能选的是同一套预设时，改的是同一份内容。想分开调，先 `新增预设` 复制一份再改。

### `沿用酒馆` 和渠道选 `沿用酒馆` 有什么区别？

下拉框里的 `沿用酒馆` 完全跟着酒馆走；渠道为 `沿用酒馆` 的预设也用酒馆连接生成，但可以单独设置 `生成参数`。两者都不能用于剧情规划。
