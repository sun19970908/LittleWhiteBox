# 小白助手

小白助手是装在酒馆里的技术支持助手。它能读酒馆和小白X的源码与文档，帮你排查报错、写角色卡和 STscript、查当前酒馆的状态，也能直接改你的角色卡。

## 启用功能

1. 打开 **扩展设置 → 小白X → 数据互动**，点 `小白助手` 按钮。
2. 第一次打开时，点窗口里的 `配置`，填好模型接口（见 [API 配置](#api-配置)），点保存。
3. 在下方输入框写下你的问题，点 `发送`。

`总开关` 关闭时，`小白助手` 按钮不可用。打开失败会提示“小白助手初始化失败”，请刷新页面后再试。

## 窗口

助手在酒馆页面上方以浮动窗口打开，右上角有这几个按钮：

| 按钮 | 作用 |
| --- | --- |
| `最小化` | 缩成一个小图标，点图标恢复 |
| `侧边栏布局` / `全屏布局` | 切换窗口占据的位置 |
| `关闭小白助手` | 关闭窗口 |

电脑上可以拖动标题栏移动窗口，拖右下角调整大小。

## API 配置

小白助手、[小白电纸书](ebook.md)、[小白酒馆](tavern.md) 和 [小白 OS](xiaobai-os.md) 的 Agent API 共用同一份模型配置。在任何一处改了，其它地方也会跟着变。

配置面板分为两页：

| 分页 | 用途 |
| --- | --- |
| `主助手 API` | 日常对话使用的模型 |
| `分身 API` | 助手把子任务交给“分身”时使用的模型，可以和主助手用不同的服务和模型 |

主要字段：

| 字段 | 说明 |
| --- | --- |
| `已存预设` | 可以存多套配置，用旁边的按钮新增、重命名、保存、删除 |
| `Provider` | 接口类型，例如 OpenAI 兼容、OpenAI Responses、Anthropic、Google AI、Google Vertex AI，以及沿用酒馆连接的「酒馆 OpenAI 兼容」「酒馆 Claude」「酒馆 Google AI」 |
| `Base URL` / `API Key` / `Model` | 接口地址、密钥、模型名 |
| `拉取模型` | 从接口读取模型列表，选中后填入；也可以选 `手动填写` 自己输入 |
| `最大输出 Token` | 单次回复的长度上限，默认 32000 |
| `Tool 调用格式` | 一般用 `原生 Tool Calling`；模型不支持工具调用时改用 `Tagged JSON 兼容模式` |
| `Reasoning 模式` / `思考强度` / `思考 Token 预算` | 控制模型的思考；预算填 `-1` 表示由模型自己决定（模型支持时） |
| `联网渠道（全局）` | 见 [联网](#联网) |

保存时按钮会显示“正在保存配置”，成功后显示“配置已保存”；失败显示“保存失败”，请检查后重试。

### 联网

在 `联网渠道（全局）` 里选 `Tavily` 或 `Exa`，再填对应的 `API Key`。两家的 Key 分开保存，切换渠道不会丢掉另一家的 Key。所有用到联网的功能共用这里的选择。

- 没填 Key 时，助手无法联网，会提示“请填写所选联网渠道的 API Key”。
- 选 `Exa` 时，需要先安装小白X后端。点下方的 `安装指引` 按步骤操作，详见 [小白X 后端](server.md)。没装后端会提示“Exa 联网需要小白盒后端”。

### 权限

| 设置 | 选项 | 默认 | 含义 |
| --- | --- | --- | --- |
| `执行权限` | `默认权限` / `完全权限` | 默认权限 | 默认权限下，助手每次执行斜杠命令都要你确认；完全权限下直接执行 |
| `JavaScript API 权限` | `禁止` / `允许` | 禁止 | 允许后，助手可以在酒馆页面里运行 JavaScript 读写酒馆状态 |

需要确认时，聊天里会出现一张卡片，写明要执行什么、目的和预期结果。点 `是，执行` 才会执行，点 `否，跳过` 则这次不执行。默认权限下，只读的 JavaScript 请求会直接运行，会修改状态的请求仍要确认。

## 对话

- 输入框旁的按钮可以 `发送图片`（PNG、JPG、WEBP、GIF）或 `选择文件` 放进工作区。
- 点一条消息可以展开操作：`复制`、`编辑`、`重答`（从这里重新生成后续回复）、`删除`。
- 回复过程中点 `终止` 可以停下。
- 助手做的每一步（读文件、搜索、执行命令）会折叠成“处理经过 · N 项操作”，展开可以看每项的结果；有失败时会标出“N 项失败”。
- 顶部的上下文圆环显示当前用了多少 token。快到上限时，助手会在下次请求前自动总结较早的历史，聊天里显示“已压缩较早历史”。
- `清空对话` 会清掉聊天记录，工作区保留，提示“对话已清空，工作区已保留”。

对话记录保存在当前浏览器里，刷新页面后还在。

## 工作区

点 `展开工作区` 打开右侧面板。工作区是助手和你一起编辑的文件夹，刷新页面、清空对话都不会清掉它。

| 操作 | 说明 |
| --- | --- |
| `新建文件` / `新建目录` | 手动建文件 |
| `导入本地文件夹源码` | 把电脑上的一个文件夹整个导入（浏览器不支持时会提示“当前环境不支持文件夹导入”） |
| `搜索文件` / `仅看已修改` | 筛选文件 |
| `当前内容` / `原始内容` / `查看差异` | 查看文件，以及和导入时相比改了什么 |
| `恢复原始内容` | 撤销对这个文件的修改 |
| `下载当前文件` / `下载全部` | 保存到电脑 |
| `清空全部` | 删除工作区里所有文件，会先确认 |

你自己在工作区里改的内容要点 `保存`。保存失败时会提示“工作区保存失败，请勿关闭页面”，草稿会留在原处，点 `重试保存` 即可。工作区有未保存修改时，清空对话和关闭窗口都会被拦下。

### 编辑角色卡

1. 在酒馆里打开一张角色卡。
2. 在工作区点 `打开角色卡文件`，角色卡会拆成多个文件放进工作区：`card.json`（名称、标签、作者、版本、主世界书）、描述性格等正文各一个 `.md`、每条开场白一个文件、绑定世界书的每个条目、角色卡里的正则和循环任务。
3. 让助手改，或者你自己改。
4. 选中改好的文件，点 `写回角色卡`。

文件在工作区编辑，写回后才修改角色卡。常见提示：

| 提示 | 怎么办 |
| --- | --- |
| `请先打开一张角色卡` | 先在酒馆里选中角色 |
| `当前角色卡已切换，请回到对应角色卡后写回` | 切回这个文件所属的角色卡再写回 |
| `这项内容已在酒馆中改过，未覆盖。重新读取这个文件后再修改。` | 你在酒馆里也改过这项。重新打开角色卡文件，再改一次 |
| `card.json 只编辑名称、标签、作者、版本和主世界书…` | 正文和世界书条目请改对应的文件 |
| `部分文件未写回` | 看提示里的具体原因，改好后再写回 |

## 记忆区

在工作区面板切到 `记忆区`，可以看到助手跨会话记住的内容：

- **身份设定**：助手的名字、性格和说话方式。直接告诉助手你希望它是什么样，它会自己保存。
- **工作记录**：长期结论、经验和你特别交代的事。
- **技能**：助手把做过的复杂任务整理成可复用的步骤。整理前会出现“待确认的技能沉淀”卡片，点 `是，生成` 才会保存。

## 注意事项

- 助手能读源码和文档，但读不到你的电脑文件，除非你导入到工作区。
- 给助手 `完全权限` 前想清楚：它执行斜杠命令时不会再问你。
- 关闭 `总开关` 会关掉助手。

## 常见问题

### 发送后一直没有回复，或提示连接失败

检查 [API 配置](#api-配置) 里的地址、Key 和模型；可以先点 `拉取模型` 试试接口通不通。仍然不行，打开 [监控台](tools.md#监控台) 看错误日志。

### 提示“存档读取失败，已停止加载。请重新打开助手。”

关闭助手窗口再打开。反复出现时刷新酒馆页面。

### 助手说它不能运行 JavaScript

`JavaScript API 权限` 默认是 `禁止`。到 [权限](#权限) 改成 `允许` 并保存。

### 模型报错说不支持工具

把 `Tool 调用格式` 改成 `Tagged JSON 兼容模式` 再试。
