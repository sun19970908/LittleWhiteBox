# 小白电纸书

小白电纸书是一个和 AI 一起写长篇的地方：你在创作台和写作助手商量、搭大纲、写章节，然后在阅读器里像读书一样读自己的书稿。

## 启用功能

打开 **扩展设置 → 小白X → 数据互动**，点 `电纸书` 按钮。电纸书会盖满整个页面，打开后先看到书架。

`总开关` 关闭时按钮不可用。打开失败会提示“电纸书初始化失败”，请刷新页面后再试。

第一次写作前，要在创作台点 `API配置` 填好模型，见 [API 配置](#api-配置)。

## 书架

| 操作 | 说明 |
| --- | --- |
| `新建书稿` | 新建一本书 |
| 点一本书 | 进入这本书，选择 `创作台`（写作）或 `阅读`（阅读器） |
| `删除书稿` | 进入删除模式，再点一本书即可删除；点 `退出删除` 结束 |
| `书籍传输` | 导出或导入作品包 |
| `切换为深色视觉` / `切换为白底黑字` | 切换配色 |
| `退出电纸书` | 关闭电纸书 |

删除会清除这本书的全部书稿和写作记录，无法恢复，删除前会再确认一次。

书稿保存在当前浏览器里。换浏览器或换设备前，请用 [导出作品包](#导出与导入) 备份。

## 创作台

创作台分三块：左边是文件目录，中间是编辑器，右边是写作助手。顶部的 `编辑` / `平衡` / `助手` 可以调整编辑器和助手的宽度。手机上用顶部的 `编辑` / `助手` 来回切换。

### 文件目录

| 分组 | 内容 |
| --- | --- |
| 正文 | 各章节。阅读器只读这里的章节 |
| 设定草稿 | 大纲、文风规则、角色设定、世界设定、状态追踪、审稿规则、卷计划、审稿意见、笔记。是写作依据，不进阅读器 |
| 导入资料 | 从酒馆导入的素材 |
| 其他 | 当前书里的其他文件 |

### 导入酒馆资料

在 `可导入` 下点按钮，把酒馆内容存成资料文件：

| 按钮 | 导入什么 |
| --- | --- |
| `聊天记录` | 当前聊天的全部楼层 |
| `角色信息` | 当前角色卡的设定 |
| `剧情总结` | 小白X剧情总结里的当前总结 |
| `世界书` | 当前角色和聊天关联世界书中启用的条目 |

内容过长时会截断。没有可导入的内容时，文件里会写明原因，例如“当前没有选中角色”。

### 编辑与保存

在编辑器里改完，点 `保存`。底部显示“有未保存修改”或“已保存到书库”。有未保存修改时切换文件、离开创作台，会先问你是否放弃。

### 写作助手

在右侧输入框写指令，例如“把当前段落改得更克制一点”。也可以展开 `创作入口`，按写一本书的顺序点按钮：

| 按钮 | 助手会做什么 |
| --- | --- |
| `聊新书` | 问你 3–5 个问题，弄清想写什么，这一步不动笔 |
| `建书脊` | 写出故事主线和人物欲望链 |
| `定写法` | 写出文风、节奏、哪里写慢哪里写快的方案 |
| `整理资料` | 把导入资料整理进角色、世界、文风设定，不编造 |
| `搭大纲` | 写全书骨架和分卷（需要先 `定写法`） |
| `定当前卷` | 规划当前这一卷 |
| `按指挥写` | 只写你指定的章节或段落 |
| `试写开场` | 给出 2–3 种开场供你挑选，不写进文件 |

助手需要审稿时，会把章节交给独立的“审稿分身”检查，再把意见写进审稿文件，之后按意见修订。审稿分身使用 `分身 API` 的配置。

工具栏的 `清空对话` 清掉和助手的聊天，不影响书稿。助手消息同样支持复制、编辑、从这里重新生成和删除。

### 配图

在正文章节点 `配图`，会按章节内容生成一张插图插入正文。生成中按钮变为 `停止`。按钮不可用时，鼠标悬停会显示原因，例如“画图后端未启用”“当前章节没有正文”。画图后端的设置见 [AI 画图](draw.md)。

配图期间如果你改了这一章，生成完会问你是否把图插到章节末尾，不会重新生成，也不会再次消耗额度。

## API 配置

在创作台工具栏点 `API配置`。这里和[小白助手](assistant.md#api-配置)用的是同一份配置，填写方法相同。`分身 API` 页用于审稿分身。

## 阅读器

从书本入口点 `阅读`，或在创作台点 `阅读器`。

- `目录` 打开章节列表，顶部显示“第 N / M 章”。
- 章节末尾有 `上一章` / `下一章`。
- 朗读按钮可以朗读当前章节，需要先开启 [豆包语音](tts.md)。浏览器拦截自动播放时，会提示“朗读被浏览器阻止，请再点一次播放”。
- 还没有正文时，点 `去创作台` 写第一章。

## 导出与导入

在书架点 `书籍传输`：

- `导出作品包`：把一本书的全部文件和阅读器里的配图打成一个 `.json` 文件下载。
- `导入作品包`：选择作品包文件，导入为书架上的书。

不是电纸书作品包或版本不支持时，会提示“不是小白电纸书作品包”或“作品包版本不支持”。

## 注意事项

- 书稿存在浏览器里，清理浏览器数据会丢失，记得定期导出。
- 写作助手只能读写这本书里的文件。
- 删除书稿无法撤销。

## 常见问题

### 输入框显示“先补好 API 和模型信息”

还没有配置模型。点 `API配置` 填好并保存。

### 配图按钮是灰的

当前文件不是正文章节、章节没有正文，或者画图后端没开。悬停按钮看原因。

### 朗读按钮提示“TTS 语音模块未启用”

到 **扩展设置 → 小白X → 辅助工具** 开启 `启用 TTS 语音`，详见 [豆包语音](tts.md)。
