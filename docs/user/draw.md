# AI 画图

AI 画图让聊天自动或按需配上插图。小白X 先读 AI 的回复，找出适合画的场景，再写好 TAG，交给你选的画图服务出图，图片直接插进这层楼的正文里。支持 NovelAI、SD WebUI 和 ComfyUI 三种画图服务。

想在自己写的卡片里调用画图，见[画图与语音接口](media-api.md)。

## 启用功能

1. 打开 **扩展设置 → 小白X → 辅助工具 → AI 画图**。
2. 在 `画图后端` 里选一个：`NovelAI`、`SD WebUI` 或 `ComfyUI`。选 `关闭` 就是不用画图。
3. 点旁边的 `画图设置`，打开这个服务的设置面板，按[第一次出图](#第一次出图)把它配好。

- 后端还是 `关闭` 时点 `画图设置`，会提示“请先选择画图后端”。
- 刚切换后端、画图功能还在加载时，会提示“画图模块还没有初始化完成”，稍等再点。
- [默认开关](tools.md) 会把 `画图后端` 恢复成 `关闭`。

## 选哪种画图服务

| 服务 | 适合谁 | 你需要准备 |
| --- | --- | --- |
| NovelAI | 有 NovelAI 订阅，想要稳定的二次元画风 | NovelAI API Key（`pst-` 开头）；出图会消耗你账号的 Anlas 点数 |
| SD WebUI | 自己电脑或服务器上跑着 Stable Diffusion WebUI | WebUI 地址，并且 WebUI 已开启 API |
| ComfyUI | 自己跑 ComfyUI，或想用自己的工作流 | ComfyUI 地址；用自定义工作流时还要导出 API 格式的工作流 |

三种服务共用同一套“场景分析 → 写 TAG → 出图 → 插进正文”的流程，也共用场景 Agent、角色标签、世界书和图库。

## 设置面板

面板顶部一行：

| 控件 | 作用 |
| --- | --- |
| `楼层` | 在每条 AI 回复上显示画图按钮 |
| `悬浮` | 在页面上显示一个可拖动的悬浮画图按钮 |
| `手动` / `自动` | 手动：你点按钮才画；自动：AI 每次回复完自动配图 |
| `✕` | 关闭面板（也可以按 Esc；有菜单、对话框开着，或角色编辑还没保存时，Esc 不会关） |

左侧（手机上是底部）是各个页面：

| 页面 | 内容 |
| --- | --- |
| `快速测试` | 不进聊天，直接用一串 TAG 试画 |
| `API 配置` | 连接画图服务；是否使用小白X后台任务 |
| `工作流配置` | 仅 ComfyUI：选模型或导入自己的工作流 |
| `绘图参数` | 模型、采样器、尺寸、步数等出图参数，以及固定加在每张图上的 TAG |
| `场景 Agent` | 负责读正文、规划画面、写 TAG 的那个 AI 模型 |
| `角色标签` | 角色库：让同一个角色每次画出来都长一个样 |
| `图片管理` | 生成过的图、存储与清理、保存到酒馆 |
| `提示词模板` | 场景分析用的提示词，以及发给分析模型前过滤掉哪些内容 |
| `世界书` | 让场景分析参考世界书里的设定 |

`场景 Agent`、`角色标签`、`世界书` 和图片管理里的存储设置三种服务共用，切换后端不用重配；提示词预设和 `绘图参数` 每种服务各有一套。

## 第一次出图

不论哪种服务，都要先在 `场景 Agent` 页选好一个可用的模型（见[场景 Agent](#场景-agent)），否则只有快速测试能出图，聊天里配不了图。

### NovelAI

1. 打开 `API 配置`，在 `NovelAI API Key` 填你的 Key。Key 只存在你本地浏览器里。
2. `发送方式`：
   - `前端直连`：浏览器直接请求 NovelAI。用第三方端点时，对方要支持跨域并且证书有效。
   - `后端发送`：由酒馆后端代发，可以绕过跨域和自签证书问题。需要安装[小白X 后端](server.md)。
3. 用第三方服务时，在 `第三方端点 URL（可选）` 填它的地址；连自签证书的端点再勾选 `忽略证书验证`。
4. 点 `保存`，再点 `测试连接`。
5. 打开 `快速测试`，用默认的 `测试 TAG` 点 `生成`，能出图就说明连上了。

`超时时间 (秒)` 默认 60，`请求间隔 (毫秒)` 默认 `15000-30000`，一次要画多张图时，每张之间会随机等这么久，避免请求太密。

### SD WebUI

1. 打开 `API 配置`，在 `SD WebUI 地址` 填地址，例如 `http://127.0.0.1:7860`。
2. 这个地址要**酒馆服务器**能访问到。酒馆在 VPS、SD 在你自己电脑上时，需要内网穿透、组网或公网地址。
3. WebUI 设了登录时，在 `认证信息` 填 `用户名:密码`。
4. 点 `测试连接`，看到“SD WebUI 连接成功”后点 `保存`。
5. 点 `拉取模型 / 采样器`，然后到 `绘图参数` 里选模型和采样器。
6. 在 `快速测试` 点 `生成` 试一张。

小白X 是通过 API 出图的，**WebUI 网页上填的 TAG 和参数不会生效**。正向、负向 TAG 和出图参数都要填在小白X 的 `绘图参数` 里。`模型` 选 `不切换后端已加载模型` 时，会用 WebUI 当前已经加载的那个模型。

### ComfyUI

1. 打开 `API 配置`，选 `连接方式`：
   - `酒馆后端代理`：请求经酒馆转发，地址填**酒馆服务器**能访问到的。这种方式不填认证信息。
   - `浏览器直连`：从你当前的浏览器访问 ComfyUI，地址填**这台设备**能访问到的。ComfyUI 需要允许跨域。需要登录时在 `认证信息` 填 `用户名:密码`。
2. 填 `ComfyUI 地址`，例如 `http://127.0.0.1:8188`，点 `测试连接`，再点 `保存`。
3. 打开 `工作流配置`，选 `出图模式`：
   - `简单模式`：点 `拉取模型`，选一个模型就能画。`高级参数` 里可以调采样器、调度器、Steps 和 CFG Scale。
   - `自定义工作流`：导入你自己的工作流，见下文。
4. 在 `快速测试` 点 `生成` 试一张。

**导入自定义工作流**

1. 在 ComfyUI 界面点右上角菜单 → **Save (API Format)**，下载 JSON 文件。必须是 API 格式，普通的 Save 不行，导入时会提示“工作流格式错误：需要 API Format workflow JSON”。
2. 在 `工作流 JSON` 里导入或粘贴，看到“工作流已导入，请配置节点映射后保存”。
3. 填节点映射：`正向提示词节点` 和 `SaveImage 节点 ID` 必填；`负向提示词节点`、`宽度节点 ID`、`高度节点 ID`、`Seed 节点 ID` 按需填。节点 ID 就是 JSON 里每个节点前面的编号。
4. 点 `保存`。

自定义工作流里的采样器、Steps、CFG、随机种子等都按你工作流里配好的来，小白X 只负责填入提示词和尺寸。

## 场景 Agent

`场景 Agent` 页设置的是“读正文、规划画几张图、每张画什么、写出 TAG”的那个 AI 模型，不是画图模型本身。

- 这里的 API 预设和小白X 其他 AI 功能（例如小白助手）共用同一套，在这里改了，别处也会跟着变。
- 面板会显示当前用的是哪个预设，例如“预设「默认」 · 某服务 / 某模型”。还没选模型时显示 `未选择模型`，这时配图会失败，提示“共享主预设「…」尚未选择模型。”。
- `失败自动重试`：场景分析失败时自动重试几次，默认 3 次，填 0 关闭。它只重试分析，不重试出图；重试会多花 API 额度。

## 在聊天里配图

### 楼层按钮和悬浮按钮

- **楼层按钮**：每条 AI 回复上一个小胶囊。点画笔图标给这层楼配图，点旁边的小箭头展开快捷菜单。
- **悬浮按钮**：一个可以拖到屏幕任意位置的按钮，靠边时会半隐藏。它只给**最后一条 AI 回复**配图；聊天里没有 AI 回复时会提示“没有可配图的AI消息”。

在设置面板顶部勾选 `楼层`、`悬浮` 控制它们显示与否。SD WebUI 和 ComfyUI 默认两个都显示；NovelAI 默认只显示楼层按钮，要用悬浮按钮请勾上 `悬浮`。

快捷菜单里可以临时改：

| 项目 | 说明 |
| --- | --- |
| `预设` | 仅 SD WebUI / ComfyUI：切换绘图参数预设 |
| 画师串预设 | 仅 NovelAI：点缩略图切换 |
| `尺寸` | `跟随预设`，或临时指定竖图、横图、方图等；NovelAI 还可以选 `AI 自动（按构图）` |
| `数目` | 这次要几张图：留空跟随预设，填 `0` 表示不指定、让 AI 自己决定，填 1–20 指定张数 |
| `自动配图` | 点一下在自动、手动之间切换，和设置面板顶部的 `手动` / `自动` 是同一个开关 |
| 齿轮 | 打开设置面板 |

**画图过程中**，胶囊会显示两个字的状态，例如 `分析`、`生成`、`排队`、`等待`、`重试`；重试时显示 `重1/3` 这样的次数。这时再点一下胶囊就是中止，提示“正在中止”。画完后会显示结果，例如 `2/2 成功`、`1 张失败`、用时，以及失败原因。

### 自动配图

把模式切到 `自动` 后，AI 每次回复结束，小白X 会给这条回复自动配图。以下情况不会自动画：

- 最后一条是你自己发的消息。
- 回复正文太短（不到 50 个字）。
- 这条回复已经自动配过图了。
- 这层楼已经有画图任务在进行。

### 自动排队生图（NovelAI）

NovelAI 的 `API 配置` 里有 `自动排队生图`，默认开启。关掉后，场景分析照常进行、TAG 照常写好，但每张图都停在“待手动生成”，你点 `生成` 才真正出图、才扣点数，不合适的画面可以直接跳过。

这个选项和 `使用小白X后台任务` 不能同时生效：关掉自动排队时，后台任务会自动让路。

### 让 AI 在正文里点名画什么

AI 可以直接在回复里写 `[img:TAG]`（也可以写 `[图片:TAG]`），例如：

```text
她推开窗，晨光洒进房间。[img:1girl, opening window, morning light, indoor]
```

- 回复写完后，这个标记会变成一张图片卡片，直接按里面的 TAG 出图，不再经过场景分析。
- 写在代码块或行内代码里的标记不会被当成画图请求。
- 只有刚刚生成的那条回复会自动出图；旧楼层里的标记显示为“尚未绘图”，点 `生成` 才画。
- NovelAI 关闭了 `自动排队生图` 时，新标记显示“待手动生成”，同样点 `生成` 出图。

你可以把“需要配图时用 `[img:TAG]` 标出来”写进角色卡或预设，让 AI 自己决定在哪里配图。

### 图片卡片上的操作

已出图的卡片：

| 操作 | 说明 |
| --- | --- |
| 点图片 / `放大` | 打开图库，查看这个位置的所有历史版本 |
| 左右箭头 | 在历史版本之间切换；在最新版本上点右箭头就是重新生成 |
| `保存到服务器` | 把图片存进酒馆的图片文件夹 |
| `重新生成` | 用同样的 TAG 再画一张，旧图保留在历史版本里 |
| `编辑TAG` | 修改这张图的 TAG（场景描述），保存后可以 `保存并重试` |
| `删除` | 删除这张图 |

失败或未生成的卡片会显示 `重新生成` 或 `生成`，有旧图时还有 `返回已有图片`；`…` 菜单里有 `编辑 TAG`、`重画本楼失败图`（只重画这层楼失败或结果未知的图，已成功的不动）和 `移除`。

图片上方是否显示标题，在 `绘图参数` 的 `图片标题` 里选：`不显示`、`图上标题` 或 `可折叠标题`。切换即保存，三种服务通用。

## 绘图参数

每种服务都可以存多套参数预设，用 `新建`、`保存` 等按钮管理。

- **正向固定 / 负向固定**：每张图都会加上的 TAG，适合放画风、质量词、通用负面词。
- **要求出图数**：一次配图让 AI 规划几张，默认 2，`0` 表示不指定。
- **每张图最大角色数**（SD / ComfyUI 叫 `单图最大角色数`）：限制一张图里最多几个角色，`0` 不限制。
- **尺寸**：选常用尺寸或自定义宽高。

各服务特有的参数：

- **NovelAI**：模型（V5、V4.5、V4、V3 等）、采样器、调度器、Steps / CFG / Seed，以及质量增强、负面预设、Vibe 氛围转移等。Vibe 编码会消耗 Anlas 点数，只在你手动点击时才编码；Vibe 组可以导出，换设备导入后不用再花点数。
- **SD WebUI**：模型、采样器、Steps / CFG / Seed、`批量数量 / 批次数`（显存不够时保持 1 / 1）、`Clip Skip`、`修复面部`、`平铺`、`启用 Hires.fix`（默认关，开了显存压力更大）。
- **ComfyUI**：`尺寸覆盖`；其余参数在 `工作流配置` 里。

## 提示词模板

这里是给场景 Agent 的提示词，一般不用改。可以存多套预设，改坏了点 `恢复默认` 或 `全部恢复默认`。

**消息过滤规则** 决定发给场景 Agent 之前，从正文里去掉哪些内容。默认会去掉思考块（`<think>`、`<thinking>`）以及 `<system>`、`<meta>`、`<options>`、`<state>`、`<UpdateVariable>` 等标签里的内容。

- 每条规则填起始和结束；起始留空表示从消息开头过滤，结束留空表示过滤到消息末尾。
- 被过滤的内容既不给 AI 看，也不会在那里插图。勾选 `发给 AI` 后，这段内容会给 AI 看，但仍然不在里面插图，适合对话美化之类的内容。

**最近请求记录** 能看到最近几次场景分析发了什么、模型回了什么，配图结果不对劲时可以来这里查。

## 世界书

在 `世界书` 页可以让场景分析参考世界书里的设定，例如角色外貌、场景布置。

- `使用酒馆当前世界书`：按酒馆自己的规则扫描当前已启用的世界书。
- `启用画图上传世界书`：上传酒馆导出的 `.json` 世界书文件，专门给画图用。`过滤模式` 选 `自动 (简化关键词过滤)` 时，常驻条目总是带上，普通条目按关键词匹配，禁用条目不带；选 `全部激活条目` 则全部带上。

两者可以同时开。

## 角色标签

角色标签是画图用的角色库：给角色填好名字、别名、固定外貌和服装，AI 在正文里认出这个角色时，就会用你写好的 TAG，让同一个角色每次画出来都一个样。

### 添加角色

1. 打开 `角色标签`，点 `添加角色`。
2. 填角色名称和别名（逗号分隔）。正文里出现名字或别名，就会认出这个角色。
3. 填类型（例如 `girl`、`boy`、`no humans`）、固定外貌、服装和避免的特征。
4. 保存。

角色还可以有多个**形态**（例如人形、兽形），每个形态有自己的外貌、服装和动态标签；正文没提到时用第一个形态。形态、服装、动态标签的名称不是触发关键词，而是给 AI 看的描述，可以用自然语言写，例如“礼服，正式场合”。

### 分组与批量管理

- 角色可以分组。关闭一个分组，组内角色就都不参与出图，各角色自己的开关保持不变。
- `多选` 后可以批量 `启用`、`停用`、`移到`、`复制到`、`导出所选`、`删除`。删错了可以点 `撤销`。
- 上锁的角色或分组在导入时不会被覆盖，除非你勾选 `同时替换已上锁的角色`。
- `导出` / `导入` 用来备份或分享角色库。导入时可以选遇到相同角色是替换、跳过还是保留两者。

### 分组预设

不同角色卡用不同的角色组时，可以用分组预设自动切换：

1. 先把各分组的开关调成这张角色卡要用的样子。
2. 点 `存为预设`，再点 `绑定角色卡`，选上要绑定的角色卡。
3. 之后进入这些角色卡的聊天时，会自动套用这个预设的分组开关。

多个预设同时命中时，排在最前面的优先。没命中任何预设时，分组开关保持不变。预设不会改动角色卡本身。

### 智能辅助（NovelAI）

- `自动学习角色`：生成图片时，自动记下 AI 识别出的新角色，存进 `新角色保存到` 指定的分组。勾选 `同时补全已有角色空白外貌` 后，也会补全已有角色没填的外貌。默认关闭。
- `沿用角色着装`：画新图时沿用角色上一次出图的外貌和着装，正文写明换装或其他变化时才改。默认开启。

### Danbooru 资源库

勾选后加载本地 Danbooru 角色库，可以离线搜索作品角色的官方 TAG，并填进固定外貌。这是测试功能。

## 后台任务

开启后，场景分析和批量出图交给酒馆服务器去跑。你关掉页面、刷新、断网，或者手机切到后台，任务都会继续，回来后结果会接回聊天里。

**开启方法**

1. 先安装[小白X 后端](server.md)。
2. NovelAI：`API 配置` → `发送方式` 选 `后端发送` → 勾选 `使用小白X后台任务`。
   SD WebUI / ComfyUI：`API 配置` → 勾选 `使用小白X后台任务（场景分析 + 批量出图）`。
3. 勾选后下面会出现 `安装指引` 按钮，后端没装好时可以照着装。

NovelAI 选了 `后端发送` 后，`API 配置` 里会显示后端状态，例如“littlewhitebox-server 已就绪（v3.1.0）”；装好后点 `重新检测` 刷新。

**注意事项**

- 用后台任务时，画图服务的地址要**酒馆服务器**能访问到。
- 已启用的角色超过 500 个时，后台出图请求会被拒绝。请停用暂时不用的角色，或关闭后台任务。
- 重启酒馆后，之前正在跑的后台任务不会继续。
- 后端没装、版本太旧或连不上时，配图会失败并提示原因，见[常见问题](#常见问题)。

## 图片管理与保存

### 图库

生成的图会先存在你这台设备的浏览器里。`图片管理` 页按角色列出所有图片，点缩略图打开图库，可以查看历史版本、`使用此图`（把它设为楼层里显示的版本）、保存或删除。NovelAI 还可以 `批量管理`，选中后 `导出 ZIP` 或 `删除记录`。

浏览器里的图换了设备、清了浏览器数据就看不到了。想长期保留，请保存到酒馆。

### 保存到酒馆

- 手动：点图片卡片或图库里的 `保存到服务器`，图片会存进酒馆的图片文件夹，按角色名分文件夹，之后换设备也能看到。
- 自动：在 `图片管理` → `存储与清理` 勾选 `自动保存新生成的图片`。只有勾选**之后**新生成的图会自动保存。自动保存失败时会提示“自动保存图片失败，图片仍在图库里，可手动保存”。
- `图片按日期分文件夹保存`：保存目录改成“角色名/年_月_日”。需要安装[小白X 后端](server.md)，没装时图片仍会保存到角色名文件夹，并提示“未检测到 littlewhitebox-server 插件，按日期分文件夹保存未生效”。
- `打开文件夹`：在酒馆所在的电脑上打开图片文件夹。需要安装小白X 后端，而且你要在酒馆那台电脑上操作；从手机或别的设备访问时会提示“酒馆不在本机，无法直接打开”。

### 节省空间

- `压缩新生成的图库图片`：新图存进浏览器图库时转成 JPEG，省空间。有损压缩，透明背景会变白；已有的图不变。
- `旧图转 JPEG`（NovelAI）：把图库里还是 PNG 的旧图批量转成 JPEG。会先把 PNG 原图保存到酒馆，保存失败的不会转换。
- `自动清理`：默认 3 天（可设 1–30 天）。只清理快速测试等不在聊天楼层里、也没保存到酒馆的旧图；聊天楼层里的配图不会被自动清掉。
- `清理过期` 立刻按上面的规则清理一次；`清空全部` 清掉全部图片记录。

## 注意事项

- NovelAI 每次出图都会消耗点数。不想白花点数，可以关掉 `自动排队生图`，挑满意的再点生成。
- 自动配图每次都会调用一次场景 Agent，会消耗你那边模型的额度。
- 编辑了正文或切换了回复分支后，正在进行的配图不会再写进正文。

## 常见问题

**配图失败，提示“共享 Agent 当前主预设…”或“尚未选择模型”**

场景 Agent 没配好。到 `场景 Agent` 页选一个可用的预设和模型。

**提示“正文没有可用的配图内容”**

这条回复过滤后没剩下可画的内容。检查 `提示词模板` 里的消息过滤规则是不是把正文也过滤掉了。

**提示“场景分析失败”“模型没有按要求调用场景规划 Tool”**

场景 Agent 用的模型没按要求返回画图计划。可以多重试几次，或换一个更擅长调用工具的模型。

**SD WebUI 提示“无法连接 SD WebUI”或“连接超时，请检查地址是否能被酒馆服务器访问”**

地址要酒馆服务器能访问到。酒馆在 VPS 上时，填 `127.0.0.1` 访问到的是 VPS 自己，不是你的电脑。另外确认 WebUI 开启了 API。

**SD WebUI 提示“显存不足”“请先加载模型”“SD WebUI 认证失败”**

分别对应显存不够（调小尺寸、关掉 Hires.fix、批量设回 1 / 1）、WebUI 还没加载模型、`认证信息` 不对。

**ComfyUI 偶尔拿不到图**

用 `酒馆后端代理` 时，先看看 ComfyUI 输出目录里有没有图；可以换 `浏览器直连` 对照。用 `浏览器直连` 偶发连不上时，可以换代理对照。

**NovelAI 提示认证、额度问题**

“认证信息无效或过期”请检查 API Key；“额度不足”是 Anlas 点数不够；“当前并发繁忙，请稍后重试”请稍等再试，或调大 `请求间隔`。

**提示“后台画图服务不可用”“未检测到 littlewhitebox-server”“版本过旧”**

小白X 后端没装好或版本太旧，照[小白X 后端](server.md)安装或升级。不想装的话，关掉 `使用小白X后台任务` 就会改用浏览器流程。

**提示“后台任务已过期或被清理，可重新生成”**

通常是酒馆重启过，后台任务丢了。点 `重新生成` 即可。

**提示“该楼层已有任务进行中”**

这层楼正在画，等它画完，或在胶囊上点一下中止后再试。

**提示“正文位置已变化，未写入图片”或“原文或分支已变化，未提交绘图。”**

出图期间你编辑了正文或切换了回复分支。图片没有写进正文，重新生成即可。

**提示“图片尚未保存成功，请勿刷新页面。”**

图片还在写入浏览器存储，等提示消失再刷新，否则可能丢图。

**提示“旧页面占用了图片缓存，请关闭其他酒馆页面后重新打开聊天以恢复旧图”**

你在别的标签页也开着酒馆。关掉其他酒馆页面，再重新打开聊天。
